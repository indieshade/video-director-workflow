# 实验作品与工艺记录

[外部调研风格库](researched-styles.md)是主选型入口。本页保留实验作品，不将它们冒充调研分类。

画面风格与内容规划分别记录。每个案例提供实际成片、帧预览、工艺、输入条件和可复用指导。以下不是相同提示词的对照，也不代表这些风格全部达到外部参考质量。
