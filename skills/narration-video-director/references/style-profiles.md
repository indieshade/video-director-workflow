# 风格条目：从参考名称到实际设计

用于维护风格库、解释成片为何偏离已选风格，或建立新作品的视觉方向。风格的实际采样与传播研究沿用 [风格选型与表现数据](style-selection-and-performance.md)；这里补充条目怎样指导制作。少量明确选择比更多风格形容词有用。

## 风格条目以画面语言为主体

这里的风格指材料处理、造型、构图、色彩、字体与动态质地。叙事或论证方法另属导演内容设计；可以附注内容适配，但不能让“证据引导、机制推演”等表达方法占据画面风格定义，也不能把口播需要重写当成落实某个美术方向的前提。

账号识别是独立维度：人物、头像与品牌如何进入。人物造型变化不必自动改变风格；先看其是否仍服从相同的材料、边缘、字形和动态处理。IP 形象同样可以被处理为摄影剪贴、剪纸或印刷插画。

频道与系列是参考的出处。针对具体作品或段落建立分支，不假定一个频道只有一种美术风格。用户要求某个名称时，先确认库中哪组实际画面与它相符；已有明确选择无需重问。

## 一个可用的条目

条目可以保存在现有 JSON、研究笔记或 style.md 中，无需强制增加文件。按本片需要记录：

| 维度 | 应当改变的决策 |
|---|---|
| 身份与证据 | 官方原作、参与作者作品页、第三方教程或自有改编；片内帧、项目展示图和封面分别标明，观察位置与范围可回查 |
| 适用内容 | 适合解释什么；什么题材、口播结构或素材条件会使它失效 |
| 素材与造型 | 真实记录、摄影、插画、图解各自承担什么；边缘、比例与材料如何统一 |
| 构图与空间 | 注意力从哪到哪；比较、细节放大与整体关系怎样组织；不是给每句居中摆图标 |
| 字形与文本 | 命题、数据、引文、来源、字幕的角色；描述与情绪是否由画面承担 |
| 色彩与光影 | 重点如何被区分，材料如何受光；记录可变范围，不规定所有作品同一个色板 |
| 镜头与动作 | 对象如何被观察、追踪、比较或变换；哪些运动已看见，哪些只是本片提案 |
| 段落编排与声音 | 原始材料、局部图解、情境如何交接；变化何时到达、何时允许安静观察 |
| 偏离与代价 | 看似相似却会失去辨识度的处理；需要的真实素材、绘制能力和制作成本 |

## 从条目落到本片

在现有风格说明中简短写下：选中的分支、借鉴的关系、主动改编的部分、放弃的处理及原因。可用一组具体描述表达预期，如“摄影剪贴与资料局部交替，色块切出层级，关键数据参与比较”；不以“Vox + 高级质感”结束。

新方向选型的实际预览需要暴露该分支的辨识度：让主体、辅助图形、画内文字和背景共同出现，核对材料处理、字形、边缘、版面与动态质地。纸纹、色板、圆角、缓动与阴影都是可共享的工艺，单独出现不足以证明某种风格已落实。

审片时把本片关键画面与相应参考放在一起，追问“若去掉风格名称，还能从材料、构图、信息关系和动作辨认所选方向吗？”这是创作判断，不是相似度分数，也不要求复制参考。静帧只支持静态判断；段落节奏与音画交接仍需要实际播放。

发生偏离时先辨别原因：

- **有意改编且效果成立**：准确改名为本片的混合方向，保留原参考与改编说明。用户认可的绘本人物不因标签校准而自动换掉。
- **实现未兑现选型**：修主体、版面或主动作，不靠补颗粒与动效掩盖。
- **口播与材料不支持**：解释缺失的表达条件，在适当时机提议下次补充素材或脚本；当前录音锁定时按已有内容完成，不能为了更像参考加出另一套叙事。

## 当前库的使用边界

工作区 `research/style-selection-2026-10-06/style-profiles.json` 保存首轮结构化条目，`style-library.html` 提供参考与自有改编的视觉区分。它们是可更新的工作区资料，不是技能安装包依赖。公开播放快照另存，不给风格条目打流量分。

这轮 AI 阅读成片应归为「indieshade 编辑拼贴 × 温柔绘本」：借鉴编辑式解释，人物材料和日常氛围经过 IP 改编。当前局部静帧支持这一分类，不能由此声称完成了与 Vox 的整片节奏比较。
