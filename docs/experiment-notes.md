# 我们尝试了什么，尚不能证明什么

这是一系列创作者与 AI 的迭代，不是控制了上下文、计算预算、工具与素材的模型实验。公开分享中的模型名称依据发布者与作者提供的身份信息，并未独立审计生成过程。本地历史素材没有在公开版中完整分发，因此以下是定性复盘，而不是可复核排行榜。

| 阶段 | 观察到的问题 | 可迁移的改动 |
| --- | --- | --- |
| 早期口播与图形 | 文字多、线条杂，画面像PPT，视觉重点偏离口播 | 明确观看任务、文字分工、语义重点与引用身份 |
| 第三方能力接入 | 已安装 skills 和库仍需要用户反复提醒才实际使用 | 主体实现前主动发现能力，将其对应到镜头与证据 |
| 同提示词比较 | 局部重建或只比较旧版，无法回答独立创作质量 | 保留完整要求，先独立做整片，再揭示外部标准 |
| HyperFrames 试作 | 本地若干结果改善，但不能归因于框架本身 | 区分框架、时间编排、设计投入与额外提示差异 |
| 光影与声音 | 干净可运行仍缺乏层次、段落感和动作细节 | 把背景、受光对象、效果起因、动作音与留白纳入设计 |
| 开放主题盲测 | 选题、意义与整体编排仍明显弱于外部参考 | 前置方向选型，不把一个自选形式收窄成原始要求 |
| 剪贴样段 | 风格名不足以控制材料语言 | 素材、箭头、字体与背景统一印刷/纸片处理，采用有意姿态保持 |

目前最有价值的进步是画面与口播更匹配，以及把具体失败转成可以检查的设计判断；没有证据表明技能越多必然越好，也没有证明更细提示词总能改善表现。

公开五秒样例保留原提示词、源工程、素材、MP4、关键状态和审片记录。它是风格工艺示范，没有与 Opus 同提示词对照；检查时长、字体覆盖和关键状态不等于听感或连续运动审美已验证。主观听感限制在记录和交付页中保留。

## 讲述这段探索时

可围绕一个具体变化展开：从“写入 skills 但未落实”，到“把指导对应到实际画面”，再到“发现仍有模型与概念设计差距”。同一公开提示词、额外指导和先后是否看过参考需要说清。展示真正的失败和修订，比只列工具名称更能解释流程的作用。
