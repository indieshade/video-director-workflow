# 音乐、动作与声音空间

用于加强配乐、音效或既有成片的声音。沿用成立的画面与口播，按其节奏作出声音选择；不默认换成音乐驱动的剪辑，也不把某种曲风、重击或混音参数变成固定模板。

## 声音怎样改变观看

先判断观众应感到的速度、重量、距离、情绪与段落关系，再找素材。声音可以让动作显得有弹性、有摩擦、突然或连续；与画面相反的声音也可形成有意的幽默或张力，但应能解释它怎样支持当前表达。

音乐负责较长的情绪与结构，动作音交代起动、接触、释放或落定，空间纹理支持持续运动与环境。它们可以共用一个声部，也可以留白；分轨的目的在于独立取舍，不是必须铺满三个层次。

从当前素材中找到主要到达、转折与可呼吸的区间。决定哪里跟随、哪里提前提示、哪里刻意错开；段落变化可以靠撤掉节拍、缩小声场或延长尾音，不只靠增加音量和重击。大量相似元素可读成一个群体，用少量音色变化形成短乐句，不默认逐个配声。

## 在分镜时按动作与含义选声

声音设计进入首版分镜和制作。对重要画面事件，先判断声音要帮助观众理解或感到什么，再搜集或制作素材；只有对齐时间点、笼统写“加音效”，不足以指导选声。结合当前事件判断：

- **物理动作**：起动、接触、摩擦、展开、落定的材质、重量与速度；例如纸页扫开可以强调纸面摩擦和移动。
- **信息含义**：复写、选择、确认、错误、完成等关系；例如表达完成的对勾可用有正向收束感的提示声，表达重复的动作可用紧邻双击。若画面强调的是盖印接触，则按该动作选择材质声。
- **情绪与注意力**：牵引、犹豫、紧张、释放及段落变化；可通过音色、方向、时长、强弱与留白表达，并考虑音乐和口播已承担了什么。

这些职责可组合，不要求每个事件都具备三层。画面风格影响整体声音身份，但不决定所有事件必须使用同一材质；剪贴画中的确认、视线转移和纸页滑动应按各自任务判断。

沿用现有分镜的声音列或等价记录，简要写清 `可见动作及含义 → 声音任务或留白 → 素材/处理选择 → 同步锚点`。子代理负责独立制作时，也应完成相应的选声、获取、加工、混音与本轮可完成的检查；主代理合稿时回查声音是否支持画面表达。遵守实际委派范围和制作约束，不以本节作为自行增派代理的授权。

复用同一声族可以建立联系，但要区分有意重复的动机和机械套用。连续出现的相似对象可组成一个声音短句；不同意义的事件需要重新判断音色、包络、节奏和空间。减音效数量、随机变调或统一降低音量，都不能替代这一判断。候选不合适时按用途换素材，或用成熟音频工具裁切、变速、变调、滤波与分层重组；保留来源和修改记录。

## 选择音乐与素材

选择配乐时，比较声音本身的乐器、音域、节拍密度、旋律活动、段落发展和结尾是否适合画面的身份与口播空间。只写“高级、欢快、电影感”不足以指导选择。画面已经成立时，寻找可用乐段、节拍或重音关系；BPM 接近不代表相位、乐句和结尾已经对齐。

根据可用来源和本轮范围选择授权音乐、现成音效或生成工具。生成 brief 描述用途、时间、材质、速度、空间和需要避开的干扰，保留选择自由；不把技术特征列表当成声音设计。先查当前实际可用的技能、素材解析器、账户与缓存，已有授权沿用；缺少某个生成服务不妨碍使用合适的授权素材完成当前版本。

记录选中素材的来源、许可、必要署名和修改。许可证与实际素材来源分别核验，工具仓库的许可不自动覆盖它提供的音乐。保持独立创作要求；外部参考可帮助判断质量，不自动复制其声音。

## 时间、音色与空间

短音效的文件起点通常不是听起来最重的时刻。检查前导空白、包络和主要瞬态，将需要表达的接触或落定与声音的主要到达对齐；提前或延后应服务动作感受。不要把峰值检测当成听觉判断。

同族素材可用音高、时长、频段、强弱与空间变化形成关系。滤波改善音色和频段占用，压缩控制动态，混响交代距离或空间；处理应能说明在本片中解决了什么问题。持续扫声可以由实际运动驱动声像或其他适合的属性，不给所有移动都套上长 whoosh。

口播作品先保留表达和可懂度，再选择音乐的活动程度与音效位置。避开重要词句的遮盖，必要时通过音域、密度和自动化让位；不只靠降低所有声音的总音量。无口播作品可以让音乐与动作共同承担节奏，也要检查峰值是否过密、结尾是否突兀。

## 按职责复用工具

| 当前难点 | 可复用能力与边界 |
| --- | --- |
| 获取音乐和音效 | 当前可用的 `media-use` / 素材库 / 生成服务负责解析与出处，导演选择用途和乐段；不为每个任务强制安装新服务 |
| 音轨、总线与自动化 | HyperFrames 项目读取 `hyperframes-audio` 的当前版本指导，把实际素材放入对应轨道；其他框架沿用其音频规范 |
| 节拍、保音高变速与编辑拆层 | librosa 等成熟分析工具；节拍检测需核对真实乐句。HPSS 是谐波/打击编辑层，不是可靠的人声/乐器分离，也不冒充作者原生分轨 |
| 滤波、变调、动态与音效处理 | Pedalboard 等成熟 DSP 库或现有音频编辑器；安装后检查处理后的实际输出，不以接入插件数量证明质量 |
| 格式、剪辑、响度和封装 | FFmpeg 与现有媒体工具；测量导出文件，保留时长与同步，避免把格式工具当成音乐生成模型 |

按需分析和处理，常规剪辑不必先做分离、压缩和复杂总线。现有工程若已提供等价能力，优先复用。版本支持和参数来自当前官方文档与实际运行，避免凭印象写不受支持的效果属性。

## 比较与交付

对照实际画面复查重要声音：动作的接触与到达是否成立，信息含义和情绪是否匹配，不同事件是否误用了同一提示，以及重复、遮盖或尾音是否削弱了重点。特别核对转折和结尾，不以“所有动作都有声音”或“音效已经减少”作为完成依据；发现不合适时主动换声、调整或留白。实际听觉检查的范围仍按下文记录。

检查源轨、混音和编码后的结果：重要锚点、开头与结尾、静音/截断、响度、峰值及同步。声音局部修改可直接复用原视频流；确认画面相同后，比较才集中于声音。

判断编排差异时匹配完整版本的整体响度，避免仅因更响形成改善印象。拆轨试听用于理解层次，标明它与完整母带的增益/动态处理差别，不把各轨各自归一到同一响度破坏原有平衡。按需要提供同画面切换或关键片段，不强制每条视频交付多版。

实际听取整片才能判断音色、遮盖、声场、能量变化与画面是否协调。只有播放状态和测量时，记录已检查的技术证据，将新增声音作为可试听版本交付；不宣称已经听过或通过听感验收。根据真实反馈修订具体时间的关系，不用“再加音效”代替诊断。

## 工具依据

- [HyperFrames 官方仓库](https://github.com/heygen-com/hyperframes)：项目所用版本的音频实现与技能。
- [Spotify Pedalboard](https://github.com/spotify/pedalboard)：DSP 处理能力。
- [librosa 文档](https://librosa.org/doc/latest/index.html)：节拍分析、变速与 HPSS 的实际用途。
- [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html)：动态、响度与混音参数。

以上是工具依据；声音与当前观看意图的关系由作品判断，不是这些工具保证的结果。
