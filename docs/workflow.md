# 从输入到成片

## 1. 守住已有素材

保留脚本、录音、画幅、时长和不能重录等约束。标题不能替代正文的实际主张。实际配音的停顿、重音和词句起止支持节奏；ASR 时间戳不等于听觉重音。

## 2. 提炼观看任务，再决定媒介

为每个节拍写出：口播表达什么，观众已知什么，这一镜新增什么理解，先看哪里，变化后留下什么。重要、值得记录的命题可用文字；描述与情绪优先通过画面。引用和真实记录要有身份线索。口播说 A，不能因找到精彩素材就让画面说 B。

## 3. 主动发现能力

在主体实现前按镜头难点选择美术、字体、运动、形变、3D、光影、媒体和声音工具。写明“难点 → 工艺选择 → 所用指导/组件 → 要看的证据”。安装或读取 skill 不是效果已经落实的证明。只加载相关指导，不机械调用所有 skills。

完整新作品优先使用[独立制作入口](../skills/narration-video-director/references/independent-production.md)：获准委派时，由两名干净上下文的代理分别承担导演与制作。导演统一美术、分镜与声音意图，交接实际关键状态，并负责最终合稿；制作方依共同设计选材、加工、实现、混音和导出。主代理提炼输入、协调交接与核对交付。局部修改沿用原工程和分工，用户指定的分工与宿主权限优先。

## 4. 选型与视觉系统

先从内容构思实际画面，按需要查阅风格与工艺。用户希望参与选型，或偏好会实质改变交付而无法推断时，用风格帧和动作短样说明不同方案。参考图用于核对材料、字体和构图，动作与节奏需要查看连续片段。 [风格与工艺索引](../skills/narration-video-director/references/style-profiles.md#按需查阅风格与工艺)

## 5. 关键状态与制作

先做起点、变化、结果；主动作短样验证对象关系、重量、注意力交接和可读停留。声音在首版按动作、信息含义和情绪设计，音乐留白支持口播；不靠统一降音量或随机变调代替准确选声。框架拥有确定的视频时间；图形、shader 与粒子按同一时间定位，避免任意 seek 改变结果。

按[镜头连接与蒙太奇](../skills/narration-video-director/references/motion-and-sound.md#镜头连接与蒙太奇)在分镜时成对设计关键镜头：前镜留下什么，后镜接住什么，连接增加什么表达；再准备所需构图与素材。用实际导出帧检查精确匹配的接点，同时按内容改变情境、对象关系与景别，避免全篇重复同类道具。直切、保持和留白按需使用。

## 6. 首版后的创作复审

从观众角度检查完整产物。找最影响目标的问题，提出局部候选，实际比较，采用或回退，再复查接缝。无关键缺陷时可以保留首版，不为迭代轮数而修改。

`creative-review.json` 对应具体成片哈希。校验脚本只检查记录、证据路径和停止决定，不理解画面，也不会证明审美合格。截图、连续观看、听取声音与编码检查分别记录；取不到的感官证据如实保留。

## 7. 比较实验

保存公开原始提示词、额外指导、选型反馈、工具、素材与声音差异。盲测先完成整片自审并锁定源文件和成片，再揭示原片；后续调整另存。比较完整作品的表达、美术、动作、声音和整体节奏，不用复刻精度或与自己旧版的比较替代外部标准。
