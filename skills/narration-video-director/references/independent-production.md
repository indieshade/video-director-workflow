# 独立制作入口与交接提示词

获准委派的新作品和显著重做默认由两名干净上下文的 subagent 分别承担导演与制作，优先用 `fork_turns=none` 或等价方式。主代理负责整理输入、协调与核对交付。局部修改延续原分工，用户指定的分工、宿主权限和实验条件优先。

导演负责全篇视觉和声音意图，先形成表达，再交共用美术、实际代表画面和关键动作。制作方据此选材、加工、实现、混音和导出。导演复查实际成片并组织返修。可以先协作验证最难的动作，成熟部分并行推进。长片扩展样片时，区分已验证的场景和其他段落独有的难题，由同一导演统筹。

## 给代理哪些信息

从本片材料提炼简短 brief。交代观众、想讲的事、用户已确认的选择、配音或所选乐段与事实依据、必要文件路径和交付范围。区分必用证据、已认可设计、可选素材。已有账号时按[账号素材入口](account-assets.md)传递身份和确需使用的 IP。旧场景、道具、字体和音乐按本期表达需要检索。明确参考权限、工具条件与各自目录。

把已确认的约束和导演可自由决定的部分讲清楚。指定风格时给可用参考和本片要保留的特征；方向开放时把题材、素材和取舍交给导演。需要进一步研究或借鉴工艺时查[风格与工艺索引](style-profiles.md#按需查阅风格与工艺)。

## 可直接填写的双代理交接

按实际任务填入方括号，省略无关项。原样提示词比较按实验要求传递输入。

### A · 导演

```text
你是本片导演，统一视觉、镜头和声音意图，并负责实际成片合稿。
观看目标与输入：[观众与主题、口播或音乐选段、事实与必用素材、交付范围]
已确认的决定：[本片已有设计或必须遵守的美术特征；无则省略]
制作约束：[画幅、时间、工具、账号与资料边界、你的编辑目录]
使用[导演 skill 路径]。自己决定怎样让观众看懂或感受到主题。交给制作方实际代表画面，指出哪个细节承载本段意思、镜头怎样接续。有声音时给出对应的原句或乐句位置。收到成片后复查最影响表达的地方，提出具体修订并核对结果。
```

### B · 制作

```text
你是本片制作代理，在[制作目录]制作素材和动画，按需加入字幕与声音并导出。
导演交接：[分镜、实际代表画面、关键姿态与镜头连接、原句或乐句的时间位置、声音意图的路径]
输入和约束：[必须保留的素材、可自主选择的部分、框架与版本、交付格式]
使用[导演 skill 路径]和相关制作指导，按镜头需要选择或生产素材，声音随首版完成。选声按动作、含义和留白。遇到影响主表达的取舍及时反馈导演。用实际样段和导出帧检查重点到达、遮挡、阅读与匹配接缝，完成自查并交导演合稿。返回成片、可编辑源文件、主要素材出处和待复查项。
```

## 返回与合稿

沿用[创作复审](creative-iteration.md)，以实际成片核对原始委托、共同美术、跨段变化、接缝和声音。导演写明问题位置与预期改善，制作方返修后复查，主代理负责交付核对。记录实际分工、交接与复审证据。对照作品遵守[独立创作与揭示顺序](comparison-and-calibration.md#先独立创作再揭示对标)，按实验保留输入、素材和工具投入差异。
