历史观察日期：2026-10-06。下面的制作提示词是对设计语言的转化，不是原作者使用的提示词；配方均未逐条生成验证。静态观察不证明完整动态节奏，也没有风格带来高流量的因果证据。

## 编辑拼贴 · 第三方 Vox 教程

**身份：** MoSidd 第三方教程，非 Vox 原作

**关键词：** 照片剪贴 · 编辑式版面 · 半调印刷质感 · 分层场景 · 少量关键数据

0:22 的成片示例将黑白半调船只剪贴、灰色纸感网格、海面和橙色油桶符号分层组合。关键价格占据独立区域，照片承担具体对象，图标与数字承担信息。

[原作与观察位置](https://www.youtube.com/watch?v=7wuYBfE131U&t=22s)

| 维度 | 设计语言 |
| --- | --- |
| 材料 | 黑白摄影剪贴、半调、平面符号与纸面网格。摄影指出对象，数字承担必要信息。 |
| 版面 | 船只、海面、油桶和数据分层，画面中有明确主次，而非单个居中图标。 |
| 文字 | 数据和必要命题独立成层；不由教程的大数字反推本片每句都要大标题。 |
| 动态 | 建议按观察任务错峰进入，保留主体用于下一次关系变化；仅凭 0:22 静帧尚不能核验这种动作。 |
| 适用 | 具体事件、物件与少量数据可视化；有摄影素材时更可行。 |
| 偏离 | 只抄纸纹与半调，失去摄影对象、层级和解释任务。 |

[已有剪贴应用样例](../examples/collage-paper-study/README.md)：自有题材与用户指定的分帧动作，不等于原作忠实复现。

**素材制作提案（未生成验证）：**

- `object`：为{具体对象}制作灰阶摄影印刷裁片，保留辨认所需的细节；透明背景，轮廓完整。依据目标版面调整明暗和半调尺度；不生成数字或品牌标识。 检查：缩到片内尺寸后仍能辨认对象；纹理不能吞掉轮廓。

- `arrow`：把{方向关系}画成清楚的剪纸箭头，安排起点、转折和指向对象；纸边、短接触阴影和局部印刷缺墨与摄影裁片统一。 检查：指向关系先成立；删去装饰后仍能读懂。

- `type`：将{必要命题}编排成纸条或印刷标题，按语气选择中文宋体或黑体并验证授权与字形；字腔可读后再做裁边、轻微磨损和套色。 检查：中文文本在真实镜头尺寸与保持时间内能读清。

**身份：** Vox 原作；局部片内状态

**关键词：** 黑白主体 · 精确细线 · 纸面纹理 · 证据与图解交接

已核查 1:35 的地图图解、1:38 的局部放大和 1:43 的真实地图界面：粗轮廓承担主形，细边界承担细节，图解与真实记录解释同一对象。

[原作与观察位置](https://www.youtube.com/watch?v=kIID5FDi2JQ&t=98s)

| 维度 | 设计语言 |

| 材料 | 地图轮廓、细边界与真实地图界面；精度和可辨认性优先。 |
| 版面 | 大尺度关系与局部细节切换；粗轮廓承担主形，细线承担内部信息。 |
| 文字 | 标签负责对象指代和必要区别，字幕负责语言跟随；不能让细字与图形争夺观察。 |
| 动态 | 已有 1:35、1:38、1:43 状态观察；本片可试对象放大与记录承接，尚无完整连续动作审查。 |
| 适用 | 尺度、比较与机制关系明确的知识解释。 |
| 偏离 | 借来地图外观当装饰，或把一次信息比较铺成全屏关系网。 |

**制作状态：** 已研究；本公开库尚无对应原创样片。

**素材制作提案（未生成验证）：**

- `map`：根据{真实空间关系}制作有来源的地图或机制轮廓：粗轮廓定义主体，细线定义必要边界；各层可独立放大。未知数据留空，不为了构图虚构。 检查：空间与事实对应；必要细节在近景可辨。

- `detail`：为{局部细节}设计整体定位框、局部放大区和对应真实资料的连续版面；视觉处理保持线重、比例及指代一致。 检查：观众能从局部回认整体，不靠补一段说明找位置。

- `label`：为{对象区别}只保留必要标签，字号与层级对应主次；来源脚注和字幕分区，避免细字贴满图形。 检查：标签明确指代，图形仍是主要观察对象。

**素材制作提案（未生成验证）：**

- `cutout`：制作关于{文化场景}的灰阶器物摄影裁片，保留具体材质与可辨轮廓；人物与器物分别输出透明层，不生成文字、logo或原作角色。 检查：器物能建立情境，透明边缘没有脏边。

- `color-shape`：用{主体对象}周围的少量彩色形片建立不对称拼贴构图；颜色根据当前主题选择，形片与摄影裁片产生明确遮挡。 检查：彩色部分帮助轮廓和层级，不只是荧光描边。

- `space`：为{器物组合}安排接触点、前后遮挡及一致方向的地面影子；分层可用于后续动画，先验证静态空间。 检查：器物站得住，阴影对应光源；动态节奏另行试验。

## 绘画式日常情境

**身份：** TED-Ed 具体作品；不是其全频道统一规范

**关键词：** 手绘轮廓 · 纸感底色 · 叠色与排线 · 人物表情 · 局部具象符号

0:45 的人物被零散符号环绕，1:04 聚焦表情。粗细不完全均匀的轮廓、局部排线和底色共同提供绘画感；它与另一条 TED-Ed 参考的粗形剪影明显不同。

[原作与观察位置](https://www.youtube.com/watch?v=N2uQWfV6Jr4&t=64s)

| 维度 | 设计语言 |
| --- | --- |
| 材料 | 有粗细变化的手绘轮廓、排线、叠色与纸感底色。 |
| 版面 | 人物表情和处境为中心，辅助符号受主角关系支配。 |
| 文字 | 情绪由人物与环境承担；本片不自动沿用参考中的散落字母。 |
| 动态 | 已观察 0:45 与 1:04 状态；人物姿态与景别变化可作本片提案，尚未核验完整动作。 |
| 适用 | 个人经历、学习状态和亲切的解释语气。 |
| 偏离 | 把完整插画反复缩放，缺少口播语义引起的姿态或场景变化。 |

**制作状态：** 已研究；本公开库尚无对应原创样片。

**素材制作提案（未生成验证）：**

- `person`：绘制处于{日常情境}的原创人物，使用有粗细变化的手绘轮廓、克制排线和纸感叠色；完整身体与道具分层，不照搬参考人物。 检查：表情、手势和道具共同说明情境。

- `environment`：为{人物行为}设计纸感绘画环境，选择少量有关系的对象，用局部排线与底色区分空间；留出人物姿态变化所需的区域。 检查：环境服务人物行为，不变成静态装饰壁纸。

- `poses`：为{情绪变化}提出起始、转折、结果几种手绘姿态，保持轮廓与对象身份；先展示姿态比较，再选择过渡方式。 检查：无须大字复述情绪也能看出变化；这是待验证提案。

- `prop`：用{任务物件}与角色的尺度、接触点和遮挡表现任务负担，保留物件本身可辨认的特征；不要增加不存在的事实。 检查：大小变化对应当前表达，不是随意把东西放大。

- `weight`：为{受力关系}设计承重、失衡和恢复的可辨姿态，确认接触点与身体重心；比较关键状态后再做动作短样。 检查：动作支持同一句口播，不把医学参考当个人诊断。
