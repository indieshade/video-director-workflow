# 风格与素材库：持续扩充，也允许退役

我们的长期方向：通过真实作品扩充画面风格、素材提示词与可迁移的设计判断，帮助当前模型做出更好的视频；当新模型已能独立完成这些判断时，逐步简化相应指导，最终允许这套补偿框架失去必要性。

这是一项研究方向，不是模型能力预测，也没有开启定期运行或自动监控。

## 当前起点

[五种风格展示](showcase.md)提供实际成片、片内静帧、原始任务与额外选择、制作方法及局限。[十五条素材提示词](../library/material-prompts.json)是从已有工艺事后提炼的起步配方，尚未逐条用于生成验证。五个案例题材不同，不能据此给模型排名；其中包含用户认为明显落后的作品。

风格是画面语言：素材处理、造型、字体、版面、色彩光影与动态质地。不要把口播改写、固定剧情或某一段镜头时序包装成风格。相同风格也应能解释不同题材。

## 每次怎样扩充

1. 从新作品的具体难点出发，寻找不同的材料或表现方式；保留参考出处与实际观察，先区分参考研究和独立检验。
2. 做可观看的风格帧和动作短样。与已获认可的方向比较，确认造型、材质、字形和运动共同成立；关键词本身不是展示结果。
3. 把有效判断整理成可改变量的素材配方，写明适用角色、生成或程序化工具、透明背景/尺寸等输出需求，以及什么现象说明失败。不要全库强制同一个色板、特效或动作模板。
4. 用新输入实际生成并放入镜头，记录工具与版本、输入、输出及审片反馈。成功的单张素材不等于整片成功；失败同样保留，并修订适用范围。
5. 提交可复核的公开内容，更新展示索引与许可。私人录音、头像、真实聊天截图和外部原片不因参与研究就自动公开。

当前展示集中在五类，下一批优先补现有库缺少的形式，例如档案照片与地图的纪实拼贴、实物桌面与定格、手绘线条与水彩纸材。它们是候选研究方向，尚不是已实现的风格条目。选什么由实际 brief 与观看需求决定，不用条目数量衡量质量。

## 如何判断指导还有没有价值

出现值得检验的新模型或重大工具变化时，在权限与预算允许的实际任务里比较三种输入条件：

| 条件 | 输入 |
| --- | --- |
| A：普通提示词 | 用户完整 brief、必需素材与交付约束 |
| B：风格与素材卡 | A 加所选风格和必要素材配方 |
| C：完整流程 | A 加导演工作流、相关 skills 和主动复审 |

尽量使用同一模型版本、素材、工具、输出规格和可比制作预算，记录每组的搜索、生成次数、时间、额外人工选择与修订。完整流程的研究和迭代不是免费优势；无法控制的差异明确写出。新的外部同提示词检验仍遵循先独立完成、自审及哈希锁定，后揭示原片。

先判断是否理解任务、信息是否切合，再比较画面关系、材料与字体、动作、声音、整体节奏及意义。条件允许时隐藏组别给用户评价。相同输入出现不同输出时，不能凭一次漂亮片段就宣布模型已经升级，或某条 skill 永远有效；需要在不同题材和风格上复核。

## 简化与停止依据

当普通输入在不同任务上已能独立做出相当的设计判断，而额外指导没有可辨认收益或反而限制创作，删除或缩短对应规则，并保留比较记录。只改善局部时，只退役那部分；不要因为一次失误继续堆叠更多硬规定。

若整个创作补偿层已经没有持续收益，就将它标为历史方法或归档，不强求模型继续服从。素材出处、许可、输入条件和技术复现仍可按实际用途保留，它们与审美补偿是否必要是不同问题。

每次维护交付具体新增案例、验证结果及删改原因；不把未来维护方向说成已经持续自动执行。
