# 现有风格提示词：首轮实际检验

**现有卡片和素材配方提供部分材料、关系指导，但本轮没有一项可标为参考风格等效通过。** [实际样段与逐案反馈](review.html)包含七段六秒无声视频及四张未经修饰的生成图。

2026-10-06，使用同一主题：读者面对整本书，找到一小段需要学习的内容。21条原配方不改写，只填变量；测试前的库哈希和每案输入/卡片哈希保存在 [manifest.json](manifest.json)。原配方可以在 `input.json` 中核对，冻结输入保留当时的未验证状态；当前库的状态另行更新。

| 层次 | 实际输入 | 实际执行 |
| --- | --- | --- |
| 图片素材 | 单条填好变量的原句＋工具透明背景选项；无参考图、无风格卡 | 四次 host imagegen；底层模型版本未由工具报告 |
| 组合与动作 | 既有风格卡＋三条原配方＋HyperFrames技术 skills＋上一步raw素材 | 七个6秒首版，HF0.8.137、GSAP3.13.0、1280×720、30fps |
| 反馈 | 自有原图、六关键帧及导出视频0.4秒间隔的15帧动作采样；既有原作局部画面/作者项目图 | 材料、造型、版面、素材契约、动作可实现性分别判断 |

生产代理是新上下文，未查看外部参考图像或旧片；既有卡片文字已经带入参考研究信息。比较者看过参考。**这不是纯配方盲测、完整工作流验证或受控模型排名。** 参考完整运动、声音与整片节奏没有在本轮核验。

## 结果

- 4条图片配方生成；12条程序化/设计配方实施；另5条未执行或因素材条件受阻。原图中偶然出现环境不算环境配方另行执行。
- 灰阶书本与器物、色片搭配部分成立；分层影子、剪贴箭头和字形仍未形成统一材料。
- 手绘人物偏成暖色完整绘本，粗形角色偏成通用可爱插图。单PNG没有独立人物、道具、多姿态，无法完成翻页或受力演出。
- 整体/局部对应、段落连续移动有作用；几何角色和统一对象世界的造型成熟度仍不足。
- 七案技术检查和媒体合同通过，均有一个嵌套结构的authoring提示；编译、导出和哈希不作为审美通过依据。

逐案 [findings.json](findings.json)、[执行计数与边界](execution-summary.json) 和各案 `report.json` 记录实际范围、局限、配方结果与交付哈希。`validation_status` 表示发生了哪种测试；`validation_result=partial` 明确表示未完全兑现。受阻条目保留未验证状态并附 `test_attempt`，不伪称21条全部执行成功。

每案的 `shot-plan.json` 和 `build-notes.json` 明确记录执行者新增的色值、字体、几何、摆位、光影参数和时序。它们不属于原配方已提供的信息。试片采用一次美术首版，不补图、抠图、换姿态或重作设计以掩盖失败；更强的新版本应另存再比较。

## 使用源码

在仓库根运行：

```sh
npm ci
npm run setup:probes
npx hyperframes check examples/style-prompt-audit/vox-editorial-collage-tutorial
npx hyperframes render examples/style-prompt-audit/vox-editorial-collage-tutorial --quality standard --workers 3 --output renders/probe.mp4
```

替换目录名即可运行其他六案。渲染需要FFmpeg与FFprobe。原渲染使用本机Microsoft YaHei；**字体文件没有分发**。公开HTML仅将该私有字体加载改为已安装Microsoft YaHei及已有系统fallback；缺该字体的系统请自行选择合规中文字体，排版可能变化。`report.json` 分别记录私有渲染源和便携源的哈希，不把便携源称为原源文件逐字相同。GSAP通过锁定npm依赖复制，不随仓库打包。

MP4、poster和raw PNG保留实际输出；没有转载外部原片、截图或第三方角色。外部来源可从既有风格卡与检验页链接查看。此轮是素材及短样诊断，不能推断跨题材、多次生成稳定性，也不能替代完整叙事、声音与运动质地的下一阶段检验。
