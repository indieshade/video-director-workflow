## 找到可以使用的配方

`showcase.json` 索引实际作品、关键词、输入条件、限制、视频、静帧、提示词说明及署名。`material-prompts.json` 提供十五条初始配方，分别用于图像生成、图形布局、字形、光影、像素和声音设计。程序化配方是设计 brief，需要相应工具实现，不是全都交给图片生成器。

先按作品的视觉任务选择条目，再将 `variables` 中的变量替换成当前需要的对象与关系。例如 `collage-reader` 中的 `{人物}` 与 `{衣服}`。不要把整套词条无差别加入每个视频。

所有初始配方的状态是 `authored_after_example_not_generation_tested`：**看过作品后提炼，但还没有逐条生成验证**。它们不等于当时实际用过的原提示词，不保证一次获得同等质量。各案例 `prompt.md` 分别记录原任务、额外指导和事后提炼的复用描述。

后续验证配方时，附上实际输入、工具/版本、结果路径、审片发现及适用边界，再更新状态为 `generation_tested_with_evidence` 并填写 `evidence`。只改状态而没有结果和反馈不能算验证。

贡献时优先补足尚未覆盖的视觉问题，提交实际预览与许可，而不是增加同义关键词。参考临摹、看参考后修订与盲测保持区别；详见[维护方法](../docs/library-roadmap.md)。
