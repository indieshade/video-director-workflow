# 美学风格选型：参考画面、设计语言与表现数据

用于新方向选型、视觉大改，或用户希望靠近公开平台中表现好的作品。已有认可方向的局部修改直接沿用；纯讨论只交付研究和建议，不自动重做成片。这里提供选型依据，具体候选预览与方向反馈仍按 [创作方向选型](comparison-and-calibration.md#创作方向选型) 执行。

## 先定义选型要解决什么

沿用已知平台、受众、主题、画幅、片长、现有声音和制作条件。缺少发布平台时，可先从用户已有参考所在平台建立探索样本，注明假设；跨平台表现不能直接迁移。不要因为某种风格播放高，就把心理叙述改成科技宣传片或改变原口播的主张。

把两个问题分别回答：**哪些具体作品获得了较高传播？哪些视觉处理适合这次内容？** 公共播放、赞评等是传播线索，不直接证明美术带来流量。题材、标题封面、账号受众、发布时间、投放和平台分发会影响结果。选型应结合传播证据、内容适配、设计辨识度和制作可行性，不能用某个频道的累计播放替整个风格背书。

## 从具体作品采样

先确定可比较的范围，再检索，而不是搜完爆款才事后定义范围。可按平台、语言、内容用途、视频格式、片长和发布年龄建立样本；实际采用哪些条件写清楚。每个来源保存单条作品，频道只用于发现和建立参照。

- **近期信号**：相近发布窗口内的作品，包含表现较好与普通的作品。最新一条、按播放排序的一条、搜索推荐结果都不是无偏样本。保留发现入口和收录规则。
- **经典参考**：长时间积累播放、视觉处理仍有启发的作品，单列为经典；不能与新发布作品的累计播放直接排名，也不能称作当前流行。
- **风格标签来自片内画面**：同一作者可做访谈、实拍、拼贴和动画；一个视频也可混用多种形式。按观察到的段落标注主次与位置，不以账号名或封面推断整片风格。
- **保留反例和未核验项**：同类题材中的普通表现、同类画面在不同账号中的表现均有价值。未查看片内画面的记录留在待审区，不参与某种风格的表现结论。

建议一条记录包含以下信息，融入本作品现有研究文档或数据文件，不必另建复杂系统：

| 信息 | 记录要求 |
|---|---|
| 身份与来源 | 平台、URL/作品 ID、标题、作者、发现入口；保留原作者，区分转载 |
| 条件 | 发布时间、采集时刻与时区、时长、画幅、长视频/短视频/直播、主题；未知填未知 |
| 公开表现 | 播放、赞、评论等原始值及取得方式；页面约数保留为约数，缺失为 null，不能写成 0 |
| 可比参照 | 同账号或相近账号、相近题材/片长/发布年龄的作品 IDs、纳入与排除原因 |
| 视觉证据 | 实际片内截图及时间位置、已观看的动作区间、观察范围；封面单列为包装参考 |
| 设计解释 | 此段的画面主角、材料、构图、字形角色、光影、信息组织与运动处理；模型推断单列 |
| 选择结论 | 采用/备选/排除/待核验及理由；传播证据和本片适配理由分别写 |

CTR、留存、完播和流量来源通常不是第三方公开数据。没有作者授权的后台数据时标为不可得，不从播放、点赞率或评论推算。平台指标口径不同，尤其 Shorts、长视频与直播，不混成一个总榜。

## 怎样筛选“表现好”的参考

先保留原始数据，再做有限的相对比较。相近发布年龄、格式和题材的同账号作品，可比较播放中位数或所在分位；需要时用 `本作品播放 / 可比组播放中位数` 描述相对表现，列出组内 IDs 和条件。这个比值是探索指标，不是“风格得分”。参照不足、样本高度异质或中位数为零时不计算。

同一采集日、相似发布日期只控制了部分发布年龄，不能假装已经拿到相同上线天数的历史表现。只有确有历次快照或后台记录，才能比较“上线第 7 天”或“第 30 天”；单次累计播放除以天数不能替代真实增长速度。若只有宽范围的横截面数据，就展示年龄差异与不确定性，暂不排名。

优先研究在不同作品、不同作者中重复出现、并且内容用途相符的视觉处理。重复出现支持继续测试，不能证明因果。少量热门案例、一个大频道或搜索结果页，只够建立候选库，不能宣布某个风格已被数据验证。不要规定一个样本数量就自动算“统计有效”。

推荐时给出可核对的简短结论：

`内容适配 → 具体画面证据 → 相对表现与参照范围 → 制作代价 → 采用的设计判断 → 尚未知的因素`

可以保留一个内容适配强、传播证据较弱的探索方向；说明理由，不让流量排序替代创作判断。爆款中不服务本片的高密度文字、快切、猎奇造型或强光效不必沿用。

## 交付能看懂的风格选型包

维护候选条目或纠正风格标签时，同时按 [风格条目与实际设计](style-profiles.md) 定义画面的材料处理、造型、字形、版面和动态质地；口播规划与论证方法独立处理，账号识别另记。保存辨识度、适配条件及偏离风险。参考板的来源名称与本片实际风格可以不同；有意改编后回写名称，避免始终声称在制作原参考风格。

参考板、原创风格帧和动作短样承担不同任务：参考板说明从哪里获得启发；原创风格帧说明本片具体长什么样；动作短样说明它如何运动和配合声音。新方向完整制作前，以少量实质不同的方案帮助选择。只有本轮是纯研究/讨论时，才可停在参考板和设计建议，标明还没有做本片预览。

每个候选包含：

1. **带出处的实际画面**：选能解释造型、构图、材料与信息组织的片内帧，附作品链接、时间位置、观察范围与数据摘要。封面与片内帧分开；不能用封面拼图冒充成片参考。参考素材用于研究，不自动取得复用授权。
2. **具体设计关键词**：把风格名称展开为可辨认的选择。例如“照片剪贴／编辑式版面／精确指示线／少量命题文字”或“角色剪影／限制色／负空间施压／动作表达情绪”。这些是候选描述，不是固定套餐。Vox、TED-Ed 等名称只用于定位某些作品，不能代替规范。
3. **本片的表达分工**：哪些段落由人物或情境承担，哪些由证据、机制图或文字承担；口播说 A 时主画面仍解释 A。描述、情绪优先画面，值得记录的知识按需留字；不因参考有大字便改成逐句大字。
4. **原创风格帧与动作短样**：使用相同的一段现有内容和实际声音，做接近成片的候选；至少让核心造型、光影、文字与动态关系能被判断。候选不同之处来自表达与画面组织，不只是换颜色。静帧不能证明缓动、音效或节奏。
5. **取舍与证据状态**：适合什么、不适合什么，哪些处理已看见、哪些仅为拟议；由代理先自审，再按已获授权的选型方式确定方向。选中方向不替代合稿审查。

关键词应覆盖对本片有用的层面：素材与造型、色彩与明暗、字体用途、版面与空间、动作性格、镜头/转场、声音关系。不用为了填满词表给每项强行加效果。“高级、电影感、Vox 风”不够；固定某个色板、字体或缓动也不等于理解风格。

参考必须改变可解释的设计决定。记录从参考中采用的关系、舍弃的处理及原因，例如保留“具体物件到机制图的尺度交接”，舍弃不合口播的快切。落定后在 `style.md` 写稳定的视觉系统及可变化范围：主体、字形角色、材料和光源逻辑保持一致，段落的构图、场景、节奏与表现方式随内容变化。稳定不等于整片循环同一组素材。

## 让选型逐渐由本账号数据校准

公开平台研究决定值得测试的方向；本账号的实际表现检验适配。在用户提供或授权读取后台数据时，记录作品版本、主题/标题封面、发布条件、流量来源和留存变化，区分包装点击与片内观看问题。观察跌点处的语义、阅读负担、声音和画面变化，再形成下一次局部设计假设。

保持可比较的条件，累积同类作品再更新偏好；同时改脚本、标题、声音与风格的结果，不能单独归因美术。平台没有曝光或留存时继续使用可得指标，但保留结论范围。选型研究不授权自动发布作品、改账号设置或联系作者。

## 同提示词盲测的边界

通用风格库可以使用；本轮指定对标的原片、封面、帧、拆解和成片描述，仍须等独立整片自审与版本锁定后揭示。发现来源属于本轮对标时，先记录不可读取的身份，停止打开其视觉。已经看过的参考如作为本轮目标，明确称为公开参考比较。流量研究不能成为提前看答案的理由。

## 指标与研究依据

- [YouTube：CTR 与曝光常见问题](https://support.google.com/youtube/answer/7628154?hl=en)：指标受内容、受众与展示位置影响。由此采用分组与条件说明，而非跨频道总播放榜。
- [YouTube：观众留存](https://support.google.com/youtube/answer/9314415?hl=en)：留存报告位于视频级 Analytics，可比较相近长度。由此区分公开数据研究与授权后台诊断。
- [YouTube：Advanced Mode](https://support.google.com/youtube/answer/16766491?hl=en)：可比较作品/作品组及相关指标。把新旧剪辑风格分组可帮助观察变化，但这里的因果限制与视觉选型方法是本工作流的研究判断。

这些来源支持指标解释；不构成对某种美术风格的推荐或流量保证。其他平台先查其当前指标口径。
