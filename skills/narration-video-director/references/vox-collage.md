# Vox 式剪贴画：材料、字形与动态质地

Vox 是出处，不是单一色板或一套纸片入场模板。既有 MoSidd 教程提供一种编辑拼贴做法，不能代替 Vox 原作与参与作者的设计。新选择从具体分支与已观察片段出发；字幕支持流程判断，静帧支持美术判断，成片节奏需要连续观看。

## 本文定义画面风格

这里的风格指整幅画面的材料与形式，不规定口播的论证结构。内容规划、证据用途与音画匹配沿用导演的相应指导；不能以那些规则代替美术处理，也不能因选择 Vox 而要求重写口播。

用户本轮确认的目标是：**素材、箭头、图形和画内文字共同构成剪贴画，而非在正常网页式元素背后加纸纹。** 类低频绘本的动作是本工作区选型方向，不声称所有 Vox 原作都采用这一时序。

交给独立制作代理时，使用 [制作交接中的 Vox 风格段](independent-production.md#vox-摄影剪贴的交接段)，把材料、版面、字形与动态语言直接带进提示词；本篇提供按需展开的美术依据。不能只交代风格名称后期待代理自行补齐，也不将旧样片的具体物件和镜头写成通用要求。

## 把所有画内元素纳入同一种材料语言

| 元素 | 具体的美术决定 |
|---|---|
| 摄影与生成素材 | 先选轮廓和比例，再按需抠图、统一明暗、限色、半调或印刷颗粒；设计裁切边缘、纸边或偏移色层，让素材像可编排的独立纸片 |
| 插画人物 | 绘本画法可以保留，但人物、物件与其他剪贴层的边缘、色阶和遮挡要协调；仅贴一张完整插画不等于形成拼贴 |
| 箭头与 SVG 图形 | 先设计优雅轮廓和粗细层级，再选择剪纸实心形、印刷线或克制手绘笔触；与主体共享颜色、纹理尺度、边缘与层次，不保留默认 UI 箭头的光滑异质感 |
| 画内文字 | 选有辨识度且中文覆盖充分的字形，核对粗细、字面、数字与内容角色；按需编成纸条、标签、剪下的字块或印刷标题，让字形与承载材料共同参与构图，不只换字号 |
| 纸面、色块与阴影 | 统一纸片厚度感、接触阴影和套色关系；通过遮挡、尺度、不对称和有限倾角组成画面，避免每个对象都套同一白边与投影 |

选适合的图像处理技术完成上述选择，先比较处理前后实际像素，再合成场景。不能在记录里写“半调、手作”却仍直接贴入原始彩色图、默认路径和整洁网页标题。不同元素不必使用同一滤镜，但必须像属于同一幅剪贴画。

质感设计从主体、字形、图形到背景同时考虑。文字形状保持可读；真实截图保留内容像素与来源身份，通过裁切、纸框和摆放融入，不靠风格处理改变证据。字幕可保持独立清晰的语言跟随层。

## 动态也应显出材料性

类低频绘本或剪纸定格感来自有意的姿态保持、分帧切换和有限动作，而非导出卡顿。用少量有设计的姿态、纸片移位、旋转、替换、遮挡与展开形成节奏；不把每个静态对象都套连续丝滑的位移或弹簧。

可按元素层选择离散姿态采样，同时让相机或必要的引导动作保持连续。输出帧率、原声音轨和字幕时钟沿用项目；若量化动作时间，应只影响该层姿态，不量化配音与字幕。低频动作是可试验的视觉选择，不规定统一帧率，也不要求全片抖动。

预览需要同时出现人物或物件、箭头、文字与背景，检查它们的边缘、印刷尺度和叠层是否统一；动作短样检查姿态保持和切换是否有意。静态拼贴合格不证明动态质地已经落实。

## 哪些设计会让“Vox”只剩标签

- 只保留米白底、红色点缀与纸纹，主体仍是统一居中的图标或人物贴纸。
- 摄影、箭头与文字使用互不相干的材料：摄影剪贴旁边仍是默认光滑 SVG 和普通网页标题。
- 用温柔绘本人物和柔光日常场景贯穿，却仍承诺摄影档案式拼贴；这种改编可以成立，但须准确命名。
- 只给静态布局加同一套连续位移与缓动，缺少纸片动作、姿态保持和分帧变化的质地。

选型和自审对照主体材料、构图、字形角色及主要观察动作。追求解释清楚与独立设计，不能为了贴近标签硬插不合口播的证据或复制参考造型。

## 可迁移规则

- 共享背景、字体和强调色，前景与中景随意思变化。
- 拆开人物、建筑、物件等素材，让构图与入场顺序可分别调整。
- 黑白半调剪贴与偏移色描边可形成印刷、纸张质感。
- 错开主体入场，用先后关系帮助辨认，不让所有物件同时弹跳。
- 在 Studio 调整比例和位置，实际配音生成后再对齐场景。

## 为新作品作出的选择

写入作品的 `style.md`，通过关键静帧验证：

| 选择 | 明确到什么程度 |
|---|---|
| 背景 | 颜色、纹理强度、是否共享；纹理不能压过细线和小字 |
| 字体 | 中文覆盖、字面与粗细性格、数字样式、印刷标题或纸条承载方式 |
| 强调色 | 哪类信息使用强调色，避免所有元素都被强调 |
| 素材 | 照片剪贴、SVG 或视频的分工，统一边缘与色调 |
| 箭头与图形 | 轮廓、笔触、纸边或印刷质感如何与其他剪贴层协调 |
| 分层 | 主体与辅助物的层次、遮挡和可读空间 |
| 动作 | 哪些层分帧保持或替换、哪些连续运动，如何形成剪纸或绘本动作感 |
| 转场 | 对象替换、平移关注区域或背景连续，需要时再换场 |

不要强迫所有素材进入半调。证据截图、正文和图表精度优先保持可辨认。风格化不提供事实证据。

色板从所选具体参考、内容语气与品牌决定。暖白、近黑和深红是既有本地样片的选择，不能自动成为下一条 Vox 方向的默认；Earworm 项目图中的珊瑚、蓝与黄色也不是通用配方。

主体可以快速入场，但落定后保持可读。说明图、比较尺度和轴线通常更稳定。保留共同对象帮助承接，例如同一组内容卡片继续参与下一句的比较。

## 常见失效

| 表现 | 优先修订 |
|---|---|
| 像连续演示文稿 | 对象跨节拍继续变化，减少整屏重置 |
| 元素各自好看，合起来不统一 | 统一素材处理和层级，先修关键静帧 |
| 弹跳过多、没有重点 | 减少同步运动，主动作完成后再出现辅助物 |
| 拼贴只是装饰 | 补上与配音主张的关系，必要时换成关系图 |
