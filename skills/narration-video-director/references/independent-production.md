# 独立制作入口与交接提示词

用于新作品完整制作、独立重做或同输入对照。获准委派的新作品与显著重做，默认采用两名独立 subagent：全篇导演与制作代理。两者分别使用干净上下文，按角色交接，不按章节各选一套美术。主代理负责协调，不计入这两名 subagent。局部修改沿用原分工；用户指定单代理、实验条件另有规定或环境不支持时遵守实际边界，明确说明采用的分工，不默默退回一人包办。委派服从宿主权限。

## 上下文与素材边界

导演和制作代理都不继承完整长对话；支持时使用 `fork_turns=none` 或等价方式。主线程保留长期经验，交接只带当前输入、用户明确选择、必要事实、相关参考和交付范围；制作代理另外收到本片导演的设计与实际预览。失败版本的分镜、代码、道具包与反复修补过程不自动传入。用户要求修订、复用或对照的版本仍按指定提供，不能以“干净上下文”为由抹掉已认可的决定。

素材分清三类：必须保留的原声／真实证据与品牌身份，已认可的本片设计，以及可选的通用素材。先从口播构思画面事件，再按需要搜索、生成或加工道具和人物姿态；账号库不决定镜头，旧资产便利不应压过表达需要。允许重新生产，不为完成复用指标套用旧场景；也不把“降低素材库影响”误解成丢弃真实截图或重画头像。

主代理提供观看目标和质量反馈，导演自主决定物件、构图与动态意图，制作代理选择实现方法；用户未指定时，主代理不提前包办逐镜设计。首版后按实际位置、看见的问题及理解损失反馈，由导演判断如何修订。简要记录两个代理的实际身份、责任与主代理介入范围，不能把合作修订称为完全无干预。

用户认可样片后，扩展全片优先延续原导演与制作代理，保持共同美术与已成立的动作，再按后续口播设计新镜头；不能把样片循环拉长，也不默认每段换一位导演。局部小修沿用，方向失效或反复局部修补仍无改善时，再交接短的当前状态给新导演。上下文隔离与角色拆分是不同变量，不能据单次结果断言上下文长度或代理数量造成质量变化。

## 全篇统一设计，按任务分工

默认分工如下，目录可沿用项目已有结构，但不能让两名代理同时改同一批源文件。

| 角色 | 责任与交付 |
| --- | --- |
| 导演 subagent | 理解整篇口播，研究参考，决定物件、构图、材料、字形、文字必要性、动态与声音意图；维护分镜、美术依据及实际代表画面，审核加工素材、动作样段与完整成片，提出返修并负责合稿。 |
| 制作 subagent | 按共同设计搜集或生成素材、加工图像、实现动画、字幕、动作音效与音乐混音，渲染并自查；维护制作源码、来源和可查看的实际输出。局部表现与技术方法可自主选择，改变主要表达或美术语言时反馈导演。 |
| 主代理 | 整理真实输入与账号资料，发起两项有边界的委派、转达交接与反馈、核对最终产物；不代替导演逐镜设计，也不充当名义上的第二个 subagent。 |

导演先形成全篇共同设计和必要的代表画面，再由制作代理展开；开场或关键动作可先协作短样验证，不要求写完所有细节才开工。交接不是只传长篇文字分镜：要让制作方看到实际材料处理、构图与关键状态；共享色板和滤镜不足以形成共同美术。

沿用分镜和风格文件，用覆盖开头、主要解释、证据与收束的实际关键帧横向核对：是否像同一个作品，镜头是否因观看任务而有区别？变化可来自特写与全景、对象尺度、视角、叠放关系和内容交接；不靠各段换字体、配色或材质制造变化，也不要求每镜复制同一布局。具体造型和工艺按本片选择。

制作可分批推进，采用共同样式、组件或可访问的材料规范，不强制工程只能有一个文件。两项委派由主代理发起，导演与制作方不递归增派代理；首版后制作方自查，导演根据实际成片合稿，必要时由原制作方返修，再核受影响位置和前后衔接。分角色不等于按章节拆开美术，也不自动增加第三名审查代理。

导演先核对代表参考、原素材、加工结果与构图，再横向合稿，最后检查实际成片的镜头连接、文字层级、音画匹配和声音含义。角色划分不增加用户逐项审批。已有认可作品支持保留干净上下文与统一美术，但不能反推当时一定有两个 subagent；当前双代理默认是新的分工选择，收益待实际作品检验。用户明确要求多风格、分章异质设计或隔离对照时按相应目标执行。

## 简短交接，保留创作空间

主代理从当前材料提炼观看目标、原声与事实来源、已确认风格、必要约束和交付范围。导演收到任务 brief 与明确的风格指导；制作方再收到本片导演交接。已选风格的关键内容直接放进两者会读到的正文，不以频道名称、风格卡链接或“自行阅读 skills”代替；完整参考仍按需读取。

风格段说明本片的材料与造型如何协调、字形和空间层次如何组织，以及可用的动作语言。它应改变设计选择，不预先指定整片物件、逐秒镜头或效果参数。已选 Vox 摄影剪贴、几何角色与心理隐喻或极简 UI 动效时，沿用下方对应交接段，不叠加其他方向的段落；其余方向按实际参考和已确认特征重写。风格尚未确定时按选型流程处理，不把主代理临时编出的风格当成用户选择。

输入区分必用素材、已认可设计、可选来源与观察参考。允许自主选材时，导演先形成表达和选材方向，制作方据此搜集、生成与加工，主代理不预先制作一套带明显构图与隐喻倾向的素材包。账号身份和真实证据先核对，通用资产按表达需要检索；用户指定的素材、品牌资产与认可设计照常保留。参考查看范围和盲测限制明确传递。

新片交接正文要带上开场的设计责任，而非只给旧素材路径。按 [开场钩子与画面设计](directing.md#开场钩子与画面设计) 要求代理先构思本期的观看事件，再按需要生产素材；账号IP和材料语言连续，不等于沿用旧片的开场姿态、物件组合或动作。

已有账号先按 [账号素材库](account-assets.md) 读取身份与已选 IP，将库入口绝对路径、本片选用分支和必要素材 ID 放入交接。通用人物、生成概念和真实记录分清；账号库提供可用资产，不要求每镜出现头像、作者名或同一人物。

交接提供必要绝对路径及可访问权限，避免只说“素材在前面的对话里”。保留既定模型和工具条件。完整作品由同一导演统筹连续设计，不默认逐镜分派；多条件比较遵守实验规定的代理数、指导和工具投入，不自动套用双代理改变实验条件，组间不互读。

主代理负责澄清不可推断的输入和协调必要的方向反馈，传递用户已经作出的选择，不把主代理尚未验证的方案写成用户要求。导演对表达与共同美术负责，制作方对实际实现负责；制作方发现方案无法成立时及时反馈，不能自行换成方便实现的全篇模板。

## 可直接填写的双代理交接

替换方括号为本次实际输入，省略无关项；保留真实约束。风格与动态语言填入正文后再委派，不留下“高级、流畅、有设计感”等空泛要求或只有参考路径的占位。用户要求原样提示词对照时保留实验文本，另记必要适配，不自动叠加本模板。

### A · 导演

```text
你是本片的独立导演，统一全篇设计并负责实际成片合稿。另一名制作代理负责实现，由主代理协调交接；你不再转派。

作品与观众：[主题、制作范围、面向谁、希望观众最后理解或感到什么]
输入：[原声、稿件、事实与必用素材的绝对路径；不一致时的依据]
账号资料（适用时）：[PROFILE.md／素材索引的绝对路径；本片选用的IP分支与必要素材ID]
素材边界：[必用证据、已认可设计与可选资产分别列明；通用库不作为预设道具包，按本段表达搜集或生产]
约束：[项目约定路径、画幅/时长、可改与不可改内容、工具版本、成本/授权及参考查看边界]
输出：[导演独立编辑目录；分镜、美术依据、必要的实际代表画面和制作交接，之后的成片复审]

# 风格与素材指导
[已确认风格：写清摄影／插画／图形与必要文字的材料关系、字形角色、版面及光影层次；可以附相关风格卡，但正文应足以指导选择。]
[动态语言：写清此方向可如何移位、保持、替换、展开、变换或交接视线；按本片挑选，不固定构图、物件、镜头数、配色或动作参数。]

# 导演流程
先统一全篇材料、字体、文字载体和动态语言，并从口播推导不同镜头的观看任务。用跨段关键帧横向检查共同美术与构图变化，再展开制作；细节可分批完善，不为省事套用全篇模板，也不把各段做成不同风格。

使用 [narration-video-director/SKILL.md 的绝对路径] 及相关 references，自主理解口播、研究选材、设计画面和声音意图，选择解决实际难点的 skills 与成熟工具。按需读取匹配版本的框架指导，不要求读完全部参考。需要用户选型时先提供实际预览，由主代理协调；已有明确创作决定以本 brief 为准。

先决定本段值得观察的事件，再选择所需素材；可选旧库不是必用清单。保持作者身份和真实证据准确，人物姿态、道具与可动画分层可为本片新生产。已认可样片的扩展延续共同美术与有效动作，后续镜头仍根据口播重新设计。

主动设计观看过程：关键意思到达时，观众先看哪里，随后看见什么关系或状态改变，其他信息怎样让位，哪里保持。自主组合对象表演、视点、明暗、显隐和空间变化；这些是选择空间，不是必用效果清单。已有漂亮静帧也要作这项判断，分层入场和整图推拉未承担关键意思时，继续设计并用实际动作检查，不等用户逐项指挥。

关键镜头连接在分镜时一起构思：前镜留下什么线索，后镜怎样接住，连接增加什么理解或感受；据此安排相邻素材的机位、形状、位置、方向或可动画层，再交制作方实现。按内容选择匹配、语义并置、直切或停留，不要求每镜特效；共同美术中仍要检查情境与对象关系是否推进，避免全篇围绕同类道具排布。具体指导见motion-and-sound.md的“镜头连接与蒙太奇”。

本期重新判断素材、字体和配乐，上一期配置只作候选。按本期内容选材，按真实文字试排成熟字体，按情绪和原声空间选乐段或留白；简记选择及复用理由，随实际代表画面交给制作方。品牌身份和合适的资产可以延续，不强制全换新，也不将某次成功的字库、道具或曲目变成默认。

声音意图随重要动作和含义写入分镜，简记“画面或语义变化→观众应注意或感到什么→声音或留白→素材/加工→同步锚点”。口播剪辑优先考虑信息到达、列举关系、转折和收束，材质拟音按表达收益选择；保留制作方选声、加工与混音的空间。向制作方交接本片设计及实际代表画面，收到样段和成片后核对实际素材、动作、文字、声音与跨段连续性；问题按时间位置和预期表达交回制作方，返修后复查，不以导出成功结束。

把开场作为本片重点创作：先根据实际内容设计能引起好奇或共鸣的可见事件，再为它搜集、生成或加工所需素材，不从现成旧资产倒推开头。保留账号识别，但不要复刻旧人物姿态加相同物件、只换标题；从第一帧到首个完整节拍实际检查吸引力、口播匹配与后文承接，若薄弱就重做设计或素材，而不只补特效。

已选参考风格时，把代表参考、原素材、加工结果与本片关键画面并排核对，让观察实际改变选材、处理和构图；动作短样和最终成片再回查，不能以看过参考或加了纸纹证明风格成立。
```

模板交代任务与质量责任，具体构图、物件和镜头由导演自主决定，实现和局部表现由制作方选择。除实际要求外，不加入统一镜头数、固定色板、逐秒动作表或必用特效清单；相关 references 在当前难点需要时再加载。

### B · 制作

由主代理将导演的当前设计与下列短交接交给第二名干净上下文的 subagent。实际代表画面、材料处理和动作意图不能在转述中丢失；不要求制作方重做一套独立美术：

```text
你是本片的独立制作代理，负责全篇素材、动画、字幕、声音、渲染与制作自查，编辑范围为[制作目录]，不再转派。
共同设计：[风格说明、已核对的实际关键帧、材料/字体/文字载体与组件的绝对路径]。
本任务：[口播与时间依据、镜头要表达的关系、关键状态与动作；前后镜头/持续对象]。
输入与边界：[必用素材、可自主选择的部分、真实记录、不可改项、匹配版本工具]。
使用[导演skill绝对路径]的相关指导和匹配版本的框架skills，在共同设计内自主选材、生产和选择实现方法；声音随首版完成。口播剪辑按导演的观看意图，优先检索匹配用途的成品效果音，组织信息到达、关系变化、转折、收束与留白；需要材质与空间时再选相应拟音。允许加工或为明确需求合成，不把同一提示音、简单波形或持续设备声默认铺满。详见sound-design.md，不固定音效数量或声族。
把导演的观看顺序与关系变化落实到实际画面，保留重点到达、上下文与保持，不把交接简化成素材依次出现。发现缺层、遮挡或工具限制妨碍表达时反馈并提出实现替代，不自行降为通用入场模板；明暗、相机和对象变化需共用时间锚点，并在中间状态核对焦点与连续性。

按设计中的镜头关系准备成对素材和实际接缝，不将其统一替换成预设转场。精确匹配的切点对照最终FPS下实际导出的切前最后一帧、切后第一帧及邻近状态，核对焦点、轮廓与方向；不用未渲染的代码终值替代。语义切换不必强求几何对准。素材或关键状态不支持连接时反馈导演，按新的表达需要补充素材，而非默认沿用旧卡片或整图推拉。
落实本期已选素材、字体角色与音乐安排，不自动复制上期资产包、字体配置或混音；候选不合适时反馈导演并重选。自查同一道具是否代替多个无关含义、字体是否实际载入并适合阅读、音乐与音效是否因机械重复削弱表达。
若需改变主要表达、构图或美术语言，向导演反馈。先提供关键动作实际样段，再完成全篇与自查，交导演合稿；按反馈返修并复查受影响处。
返回[实际成片、可编辑源码、字幕、声音事件和来源/限制]。独立目录不写入导演负责的设计文件；导出成功不等于创作完成。
```

## Vox 摄影剪贴的交接段

用户已选此方向时，默认把下面两段直接带入上面“风格与素材指导”，而不是再缩成“Vox 风格”。可以按已确认分支和素材条件适配；新题材不沿用科普样片或旧片的具体造型、镜头和时序。

```text
这里的Vox式摄影剪贴强调摄影物件、编辑式版面与有形的纸片材料。主体、必要文字、箭头和背景共同形成拼贴；自主研究具体参考，参考画面不直接冒充原创成片。可利用纸边、裁切、印刷色层、接触阴影和克制颗粒组织层次，按内容选择色彩，不固定必须使用某套配色。
画内独立文字优先成为剪下的字块、实体纸条或带纸质白边的字形；书页、稿件和物件里的字附着原载体，真实截图保留像素。全篇共享其字形、边缘与厚度，不能只让一段有纸感；字幕另用固定公共层，外观沿用本片已确认选择。动态可采用有意的姿态保持、纸片替换、展开和分帧移位，也可让必要引导动作连续；不将配音或字幕时钟量化。具体物件、构图、镜头数和动作由你根据内容设计，不套用旧样片。
```

这段指导规定文字存在时怎样处理，不要求增加文字；必要性仍按 [画内文字的选择](text-selection.md) 判断。纸片动作只是此方向的候选语言，制作代理应按语义与注意力决定取舍，不能给所有元素套同一个入场。

## 几何角色与心理隐喻的交接段

用户已选此方向时，把下面两段直接带入“风格与素材指导”，同时提供 [几何角色的造型与表演](geometric-emotion.md) 的可访问路径。它描述画面语言；隐喻、角色和情节由导演根据当前口播设计，制作方落实表演，不沿用旧例的书本或压住后回弹。

```text
本片采用原创几何角色与心理隐喻：以有辨识度的块面轮廓、克制色组和可追踪的面部或形体特征建立角色；让角色与物件的体量、距离、支撑、遮挡及留白承载当前感受。轮廓与负空间先成立，颗粒、纸感和简化明暗随后服务形体，背景也参与构图。不要把任意圆方堆放或添加眼睛当作完成角色设计。画内文字只留必要命题或辨认信息，描述和情绪主要交给姿态与关系，字幕另层；不预设粉紫色板、纸张音色或三维质感。
从口播推导本片的隐喻与动作。决定角色哪里先改变、其他部位如何回应，保持身份、接触点和空间关系可读；按含义选择预备、重心转移、挤压伸展、迟疑或保持，不强制每个动作弹跳，也不把所有内容改成受压后获救。自主搜集、生成或绘制能支持实际表演的素材；需独立运动的部件和关键姿态要实际可用，不能用一张融合插画的整体缩放冒充表演。声音随所选材质、动作和含义设计，也可留白。先用关键姿态与动作短样核对轮廓、受力和隐喻是否成立，再完成与复审本片；具体物件、构图、镜头、色彩和时序由你决定。
```

这是待新题材制作检验的入口指导，不是已验证的稳定配方。相关参考的局部观察与旧试作限制见该参考；不可将旧片表演或此处动作建议说成已完整观看的原作规律。

## 极简 UI 动效的交接段

用户已选此方向时，把下面两段直接带入“风格与素材指导”，同时提供 [极简 UI 的层级与连续运动](minimal-ui-motion.md) 的可访问路径。界面如何解释本段口播由导演设计，制作方在共同设计内实现，不沿用旧控件串、十四秒循环或特定品牌外观。

```text
本片采用极简UI动效：以经过推敲的字形、间距、轮廓、明暗和少量有作用的强调组织可读界面。让观众明确当前对象、可发生的操作和变化结果；用可追踪的内容、容器或选中状态衔接视线，背景与层次服务当前焦点。必要文字负责对象、数值和状态，不把口播改成一屏屏卡片或堆假仪表盘。自主选择字体、图标、色彩和素材，不绑定黑白、圆角、玻璃或特定App；真实记录与原创概念界面明确区分，不把自绘结果冒充真实产品功能或实验数据。
按口播含义设计状态与动作。需要操作时让点击落点、拖动接触、即时反馈和后续结果相互对应；无需手势时可由内容变化引导，鼠标不作装饰。保留对象身份，容器与内容按阅读需要分别编排，避免整体拉伸文字或反复淡出换页。依材质和任务选择缓动、轻微弹性或清晰保持，不要求每项弹跳、连续变形或同一种入场。自主搜集、生成和加工所需素材，标准图标、路径及布局过渡优先复用成熟能力；声音区分操作接收、处理中、结果确认和错误，也可留白。先用实际关键状态与主动作验证语义、层级、触点和阅读空间，再完成与复审；具体场景、构图、控件、镜头与时序由你决定。
```

这是一份待新题材检验的交接指导，不是已证明稳定的配方。既有 UI 样例的公开提示词包含明确控件链、画幅、字体、节拍和循环；这些是该作输入，不自动转入新口播任务。

## 返回与合稿

两名代理分别在分配目录工作，保留输入、设计交接、制作来源和实际输出。沿用项目已有分镜和审片文件，简要记录角色身份、交接与实际复审；不额外编写长篇流程总结。仅启动两名代理但没有发生设计交接和导演合稿，不能称为双代理流程已完成。

全篇导演先横向核对跨段画面，再从实际成片检查 brief、共同美术与镜头变化、文字载体、音画匹配、声音含义和重复感、整体节奏与衔接；主代理再核对交付。读过指导或记录写了关键词不算落实，要看实际素材处理、构图和对象关系。修订按时间位置、观察与预期改善传递，允许在共同设计内重选实现，避免在漫长上下文中逐项叠加参数。制作方自审、导演合稿与主代理核对各自记录实际观看/听审范围，不能互相代称；已有或获准的独立评审者按 [创作复审](creative-iteration.md) 执行，不为每次修改增派代理。

同输入对照继续保留各组的指导、素材和工具投入差异，不向隔离组透露其他组结果；需要揭示参考时遵守 [独立创作与揭示顺序](comparison-and-calibration.md#先独立创作再揭示对标)。同段 NASA 科普重做中，用户明确认为采用此前第2组提示词的新版更好，因此把其明确风格段保留为当前 Vox 交接默认；素材与随机运行也变化，不能据此证明字数或单项指导的因果效果，也不保证每次产出更好。后续依据新作品的实际反馈删减无收益的指导。
