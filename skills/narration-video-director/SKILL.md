# 配音视频导演

理解现有素材如何让观众跟随内容，把脚本中的意思落实为值得观察的画面变化。配音负责讲述，画面通过对象、情境、证据和变化增加理解。导演也应识别素材的表达机会，在合适的时候提出具体改进建议，与用户讨论更好的方向。所选框架的官方 skills 负责当前版本的实现规范，本技能负责视觉解释、素材设计、注意力、动作表演、光影与声音取舍。可运行、有时间码或使用某个绘图库，不能作为审美合格的证据。

## 从已有状态继续

先读取当前作品的脚本、配音、风格说明、分镜和代码中与请求相关的部分。明确表达意图、素材实际承载的信息、已获认可的设计和当前制作限制；例如能否重录、补拍或增加制作时间，已有答案直接沿用。复用已有选择，保留用户修改。

- 只讨论 workflow：交付工作流或示例，不自动搭项目、生成素材或导出视频。
- 只做分镜：完成视觉设计及制作交接，不把写代码作为验收条件。
- 制作视频：先完成能指导实现的分镜，再进入用户选择的工具；已有充分分镜时直接实施。
- 修改某处：检查该片段及必要的相邻衔接，不重新走完整访谈或重做整片。

有脚本但没有音频时，先做语义分镜和暂估时间；有音频时，用实际停顿、重音和句子起止校准。缺少真实素材时先用明确标记的占位物验证构图，不把占位结果称为成片。

只有不可推断且会改变交付的资料才需要询问，例如实际主张、发布画幅、必须沿用的素材。可推断的选择用简短假设继续。缺少主题时可以演示方法，不能把虚构主题当作用户已经选定的作品。

## 制作入口：主动发现与落实

新作品完整制作、独立重做或多条件对照，按 [独立制作入口与交接提示词](references/independent-production.md) 组织：主代理提炼目标与约束，把已选风格的材料、字形、版面和动态语言直接写入交接正文，优先交给干净上下文中的制作代理自主选材、设计音画、制作并复审，再由主代理合稿。不能只传“风格名称＋读 skills”；Vox 摄影剪贴采用该参考中的可用交接段。具体构图、物件与镜头仍由制作代理决定，详细指导按难点加载，不复制全部参考或历史对话。依宿主权限与实际委派范围执行；局部修订沿用现有工程。

新制作、显著改变视觉方案，或用户指出已安装能力未被活用时，先读 [制作规划与能力调度](references/production-planning.md)。先明确观众的最终状态，并把本片值得记住的画面事件落实为设计；在写主体代码之前，从实际 brief 和镜头难点检索相关 skills、项目依赖与已有组件。不能等用户逐项提醒才检查；只加载相关正文，不把整个技能库塞入上下文。

新作品与独立创作默认先用 HyperFrames，读取当前环境中匹配项目版本的 HyperFrames 制作指导；编排动作时选 GSAP 指导，预览或导出时选 CLI 指导。现有项目的局部修订沿用其框架，不因默认变化自动迁移。用户指定 Remotion，或已有工程与交付确实依赖它时，使用匹配版本的官方 Remotion skills。画面能力从镜头需求选择，不把 SVG、缓动、3D 或光效视为某一框架的专属能力。

沿用 `style.md` / `storyboard.md` 记录关键选择与能力对应关系，审片时回查实际接入及观看效果。局部修订只检查受影响的能力。设计判断、工具接入、输出验证分别成立；安装成功、读过 skill 或比旧版好不等于达到外部参考质量。

制作与显著重做时，按该参考中的[执行与证据闭环](references/production-planning.md#执行与证据闭环)，在关键画面、主动作与交付审片之间核对实际观看证据。分镜承诺的动作或表达尚未出现时，先修实现；这些检查由代理主动完成，不依赖用户反复提醒，也不增加逐阶段人工审批。

## 1. 确定视觉方向

新视觉方向、显著重做，或作品缺乏吸引力与性格时，读取 [从观看感受推导设计](references/aesthetic-reasoning.md)。从内容与观看意图推导注意力、形状、时间、色彩和材料的关系，再选择具体形式与工艺。原理用于作出取舍，案例提供可选做法；不把特定风格、动作阶段或参数升级为通用规则。已有成立方向的局部修订只调用所需部分。

方向尚未明确或用户希望参与视觉选择时，在完整制作前按[创作方向选型](references/comparison-and-calibration.md#创作方向选型)提供少量真正不同的自主方案，用关键画面、动作短样和具体关键词帮助判断。代理先检查候选是否符合原始 brief，再通过用户反馈或其明确委托的自主选择确定方向；已有认可方向的局部修改直接沿用。

建立新美学方向、需要参考图与设计关键词，或希望靠近平台中表现好的作品时，读取 [美学风格选型与表现数据](references/style-selection-and-performance.md)。主动从具体作品采样，把实际片内参考、可比的表现数据和本片表达分工转成候选；区分经典与近期、包装与片内设计、公开流量线索与后台留存。完整制作前将研究落实到原创风格帧和动作短样，不能以频道名、播放榜或关键词列表代替选型。

有参考片时，记录来源、位置和读取方式：字幕能证明讲解的制作流程，截图能证明静态构图，连续播放才能支持音画节奏判断。没有看过的内容写成待核验，不能仅凭标题声称已拆解。

新建或显著重做时，主动研究当前视觉难点所需的参考，按 [制作规划中的视觉研究](references/production-planning.md#让视觉研究改变设计决策) 将实际观察转成设计选择。用户无需逐项提供参考；已有充分、相符的视觉证据时复用。提炼主体与背景关系、造型、素材处理、动作与转场如何产生观看感受，再用实际关键帧或动作验证。只列链接、风格名称或“高级、流畅、有质感”，不能作为完成视觉研究的依据。

新建视觉方向，或用户反馈文字过多、像 PPT、缺乏内容设计时，读取 [视觉解释与素材制作](references/art-direction.md)。先比较具体视觉解释，再做关键画面与素材；避免仅凭色板、字号和一张分镜表直接进入整段代码。已有成立的方向或局部修改不重复探索。

重要抽象段落的解释仍不明确，需要用用户反馈校准选择，或需要讨论现有素材的改进方向时，读取 [视觉方案比较与审美校准](references/comparison-and-calibration.md)。建议说明具体问题、预期的理解收益和实施成本；可以先讨论局部提案，不强制制作多版。用具体参考、关键状态与同口播对照检验选择，区分用户确认和模型观察。

同提示词比较模型或 workflow 的创作能力时，也读取该参考，保留已知输入条件并允许独立视觉方案；按完整作品的美感、设计判断和动效完成度评价。用户要求不看原片时，按其中“先独立创作，再揭示对标”执行：整片自审并锁定源文件和成片后才读取对标视觉。参考片作为质量标准，不默认要求重建或模仿。

维护风格库、需要把参考名称落实为设计，或用户指出成片不像已选风格时，读取 [风格条目与实际设计](references/style-profiles.md)。风格主体是画面的材料处理、造型、字体、版面与动态质地，口播规划另属内容设计；核对主体、辅助图形、文字和背景是否使用一致的形式语言，并独立记录账号识别与改编。

扩充风格与素材提示词、整理公开作品展示或检验新模型下的指导收益时，读取 [库维护与模型变化](references/library-maintenance.md)。以实际作品、原始输入和验证状态支撑条目；区分事后提炼配方与已验证输入，允许无收益的指导逐步简化或退役。

用户选择 Vox 剪贴方向时，读取 [剪贴画的材料、字形与动态质地](references/vox-collage.md)，把素材、箭头与画内文字共同设计成剪贴画，核验图像处理、字体选择与有意分帧的动作。按具体参考决定处理，不自动套用固定色板、半调或帧率。

用户选择「几何角色与心理隐喻」时，读取 [几何角色的造型与表演](references/geometric-emotion.md)，并把独立制作入口中的对应交接段直接带入 brief。用角色轮廓、姿态及物件关系承载感受，明确实际可动画的素材需求；不把旧片的压缩回弹动作套给所有心理体验。

需要绘制线条或 SVG 主体，或用户反馈“像默认图表、线条廉价、图形与素材不协调”时，读取 [线条与 SVG 设计](references/vector-design.md)。先确定图形的语义、笔触层级与素材分工，再选择绘图库和质感处理；已有成立的规范直接沿用，不为小修重做整套风格探索。

解释与节奏已有进步，但对象、色彩、字形或材质仍缺乏设计感时，读取 [媒体美术与中文字体](references/media-aesthetics.md)。先修关键画面的轮廓、明暗和字体角色，再转成运动；评估外部媒体美学 skills 的实际范围，避免把网页偏好或英文阅读公式当成视频通则。

新制作或显著重做的质感设计默认考虑光影、背景与主体如何共同形成画面；涉及这些设计、动态模糊或其他特效时，读取 [光影、背景与特效](references/lighting-and-effects.md)。先把光源、受光对象、空间层级与效果到达写入视觉方案，再制作关键状态和动作样段。单纯增加辉光、颗粒或插件不算改善质感；局部修订按受影响部分处理。

## 2. 把脚本转成视觉分镜

观众反馈“信息没首没尾”、引用突然出现、对象指代不明，或需要规划连续解释时，读取 [信息编排与理解连续性](references/information-staging.md)。先核对当前口播的命题，再明确观众已知什么、本镜新增什么、由哪种媒介承载，以及如何承接下一镜。真实素材与音画匹配分别验收：口播说 A，主画面不能因为找到真实案例就改讲 B。截图可作为当前叙述的佐证；只有口播已讲到具体案例，或用户要求调整口播时，才展开案例的具体过程。

读取 [脚本与音画导演](references/directing.md)。按意思变化拆节拍，不按句号机械分镜。用户反馈口播重点没有体现时，先识别铺垫、转折和结果的语义优先级，设计可辨认的重点到达；ASR词的位置不等于声音重音。给每个节拍写出配音、理解任务、起始画面、动作、最终可读画面、配音锚点、素材与实现、必要声音处理、前后衔接及时间证据状态。

分镜写明画面增加了什么理解、观众先看哪里、哪些信息交给配音、文字为什么需要保留。先用关键画面配实际音频做粗剪，检查观看与阅读是否冲突，再制作能暴露主要难点的动作样段。通常十几到二十几秒足够；按内容调整，不固定强制长度。已有明确风格和组件时不重复做风格探索。

画面已经成立、观众却缺少消化空间时，先检查口播是否压缩了多个理解步骤。可提议补充必要的承接或解释、拆开长句、给观察留停顿；补充的语言要推动理解，不用赘述凑时长。证据截图有明确的观众任务才加入，不因真实或可用就默认叠加。建议可以讨论、调整或留到下一次录制；用户暂时不能重录时，按现有录音和主张继续完成当前范围的制作。改稿提案、重录后的音频与最终对齐分别记录，不用修改字幕伪装成配音已改。

扩展为连续段落时，按同一参考里的“段落弧线与跨镜头连续性”安排起因、转折与结果，明确持续对象的状态和切点的注意力交接。单镜头成立不等于整段节奏成立；不要平均分配强调，也不要每句重新启动一套元素。

选择画内文字，或用户反馈文字过多时，读取 [画内文字的必要性](references/text-selection.md)。先识别值得记录的知识命题、方法及证据，和情境、行为、情绪的叙述用途：前者按需保留准确文本，后者优先通过对象、动作和空间变化表达。再逐项判断删除文字会损失什么必要理解；关键词和口播重音不自动成为大标题。字幕、来源说明和文字主导的作品按各自用途处理，不机械套用字数限制。

## 3. 校准与制作

收到实际配音后，回写时间和动作锚点；需要改配音才能表达清楚时说明原因，并同步修订相关画面。

制作或检查 Remotion 时读取 [实现交接与审片](references/implementation-review.md)。选择当前环境中一套匹配项目版本的官方 Remotion skills，按任务加载，不同时叠加同名旧包和新版插件。不了解 API 时查官方文档。

按分镜选择 SVG、Rough.js、3D 或视频素材。3D 可用于空间、材质、照明或相机关系，按可见收益与制作成本选择。让可人工精调的主体、关键字和时间段保持可编辑；不要承诺任意程序化路径或 3D 内部参数都能在 Studio 拖动。

选择实现工具、补充第三方库，或发现正在手写通用绘图、路径、时间轴、媒体处理能力时，读取 [工具复用与依赖选择](references/tool-selection.md)。箭头、连接线、流程图等标准图形优先调用成熟组件或库，不用手写线身加目测三角头替代已有能力；SVG/Canvas 是绘图媒介，本身不等于已复用图形组件。把手写代码留给本片的表达、构图、数据关系与必要适配；安装后必须在实际镜头中使用并检查输出。

设计动作样段或修订机械、线性、弹跳过多的运动时，读取 [动作设计与声音](references/motion-and-sound.md)。先判断对象为什么动、应有什么性格、关键变化如何被看懂，再选择姿态、路径、时序及所需的预备或跟随；插值、缓动和动力学用于实现这些关系。画面关系错误时返回视觉方案，不把增加动画当成默认补救。

制作含声音的作品时，在分镜阶段读取 [音乐、动作与声音空间](references/sound-design.md)，按重要画面事件的动作、含义与情绪选择声音或留白，再选素材、处理和同步锚点。声音设计属于首版制作；任务已委派给子代理时也随制作要求交接，主代理合稿时回查，不等用户指出缺失后才补。加强既有音乐、音效或混音时沿用这套判断，主动选择当前可用的声音技能和工具；用实际导出和相应的听觉证据区分技术完成与听感判断。

## 4. 按作品范围审片并修订

完整制作、显著重做或需要加强主动迭代时，读取 [创作复审、迭代与停止依据](references/creative-iteration.md)。首版导出后主动从成片取证，回查观众最终状态与标志性事件，围绕最影响目标的问题形成候选、对照并取舍；记录对应版本的证据和下一步决定。已知关键缺陷仍在时继续修订，不把技术通过自动当作交付停点。局部修改与直接导出保持原范围。

连续播放检查动作锚点、阅读负担、素材衔接、视觉注意力和配音可懂度；无声作品检查动作节奏与阅读保持，不虚构声音验收。静帧检查构图、素材质感和遮挡。分别审阅视觉解释是否成立、动作与声音是否支持理解、技术是否正常。回查选定能力是否已经落到镜头，是否改变了预期观看感受；局部效果难以判断时用同镜头开关对照。发现视觉主要靠文字重复配音时，返回画面设计。把问题落到具体时间、元素和改法，修订受影响片段。

结构检查、截图检查、带声播放和实际导出是不同证据，分别报告。没有连续播放或真实配音时，不能宣称节奏已验证。未进行实片比较时不能宣称技能优于普通提示。

## 交付与持续修改

默认保持少量持久文件：`style.md` 保存本作品的视觉选择，`storyboard.md` 保存脚本、节拍及时间状态，`review.md` 在实际审片时保存发现与修改。已有等价文件就沿用，不强制改名。时间真值使用项目已有的数据来源，不另建相互冲突的时间表。

交付当前范围的成品与已验证部分，标出仍缺的音频、素材或播放证据。请求 MP4 时按现有授权完成导出；只请求设计或预览时交付相应结果，不额外设审批仪式。

需要了解分镜粒度时读取 [示例分镜](references/worked-example.md)。它是虚构演示，不是用户题材或真实测量结果。
