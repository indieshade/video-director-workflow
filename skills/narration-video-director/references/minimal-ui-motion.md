# 极简 UI 的层级与连续运动

用于已选极简 UI 动效的制作、交接与修订。本方向以字形、比例、对齐、界面层次和状态变化形成美感；不是将口播逐句放进网页卡片。主代理直接使用 [独立制作入口](independent-production.md) 的短段交接，本页按难点读取。

## 先选界面承担什么

从口播提取需要被观察的对象、关系、操作及结果，选择适合的界面表示。搜索、选择、比较、组织或反馈可以通过实际状态变化表达；不为凑控件把不相干内容装成仪表盘，也不把同一张卡片无限复用于整段。界面若只是一个隐喻，应核对它有没有改变原声的主张和因果。

分清真实产品记录、基于事实的重绘与原创概念界面。真实产品功能和数据要有可回查依据；没有发生的操作、回复和效果不冒充真实实测。概念界面可以原创，但通过适量身份线索或来源说明使观众理解其用途，不强制每角都贴“示意”字样。

## 字形、层级与材料

先推敲一张实际关键状态：主对象的尺寸、轮廓、边距、行长、对齐和负空间是否形成清楚焦点，再加入运动。少量字体角色与有意的字重、数字排版建立层级，不靠散落的小号英文、序列号和假指标制造设计感。字幕保留独立阅读区；画内文字按 [必要性](text-selection.md) 选择，重点命题也不自动成为巨型标题。

明暗、强调色、边框、圆角与阴影共同建立界面层次。它可以温暖、冷静、鲜明或严整，不固定黑白灰。模糊和玻璃会影响对比及阅读，按用途选择；纯色背景也能成立。装饰不应与当前操作抢焦点，缩到实际观看尺寸后仍能辨认关键控件与状态。

## 用变化连接注意力

优先让内容、容器、选中项或位置关系中的有意义部分延续到下一状态；不要求整片只有一个万能外壳。明确什么改变、什么保持、视线最后落在哪里。容器变化和文字进退分别设计，内容可裁切、重排、降权或稍后出现，避免把整组文字横向拉扁，或把所有界面整体隐藏后换成另一张图。

需要点击或拖动时，触点要落在实际目标上，拖动期间对象与输入保持联系；目标状态反馈与耗时结果分开，不能点击尚未到达就出现结果，也不能拖动物件却让鼠标走另一条路。触点、高亮和必要的短反馈可以说明操作已接收，不必同时加波纹、光圈、抖动和声音。无明确操作时不强加鼠标；自动整理、计算或信息变化也能成为动作原因。

动作节奏服从原声与阅读，而非默认照搬产品交互毫秒数、某首音乐或循环节拍。过渡阶段与可读保持形成强弱区别。拖动、定位与准确测量可直接对应位置，释放后的弹性按对象性格选择；惯性、过冲和动态模糊都不是精致感的必需品。进入重点状态后让文字与数值稳定可读。

## 素材与实现

自行搜集适配字体、图标、图片或真实记录，统一字体角色、图标笔触和素材层次。标准图标和箭头优先复用成熟库，数据图形使用合适的绘图能力；不要临摹品牌外观或编造数值来填空。需要录屏时保留真实结果，重绘时保留指代关系与来源。

用当前框架组织确定时间。GSAP时间线可编排容器与内容，布局变化可评估Flip，路径和图形按需要选成熟库，不要求全片使用同一种变形。Flip等基于DOM测量的工具仍须核对初始布局和任意seek；不能只在按顺序播放时正确。镜头推近与模糊需要服务观察，不能掩盖物件身份、文字变形或错误接触。

## 声音与实际合稿

按 [声音设计](sound-design.md) 在首版选择操作、反馈和留白。点击只说明输入已接收，不等于结果成功；处理中、完成、错误和撤回可有不同包络、音高关系及停顿，也可保持安静。不要给每次鼠标位移配whoosh，或用同一清脆提示覆盖所有状态。配乐若存在，保持语音空间，不将BGM单独响度标准化。

自审实际成片的关键状态、过渡中段、触点、结果与相邻衔接：是否看得出同一对象，文字是否变形或来不及读，结果是否与原声一致，声音有没有提前误报。特别核对字幕、界面文本与角标是否在争夺同一注意力。静帧、密集序列、实时连续观看、真实听审及技术测量按实际完成范围记录，不混称通过。

## 依据与观察边界

- [Material Design 1：Choreography](https://m1.material.io/motion/choreography.html)：历史版规范；本轮读取其共享焦点、操作起点与内容承接的文字说明，没有据此声称看过所有嵌入动画，也不照搬其固定时长。
- [Fluent 2：Motion](https://fluent2.microsoft.design/motion)：界面运动服务反馈与注意力的设计参考；视频中的编排仍需按原声和画幅验证。
- [GSAP Flip](https://gsap.com/docs/v3/Plugins/Flip/)：布局状态过渡能力，不保证构图、语义或审美；实际API按项目版本核对。

工作区旧《Soft Signal》有明确控件链和带参考上下文；可作工艺记录，不是新口播自动成立的风格证明。本入口尚待本轮独立制作检验，不固定旧片的色板、字体、方形画幅、十四秒或循环形式。
