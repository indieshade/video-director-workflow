# 账号与统一素材库

已有账号制作先找身份与素材入口，不从人物素材猜作者，也不依赖长对话记忆。

## 发现入口

优先使用用户、当前 brief 或工作区 AGENTS 指定的账号资料。未指定时，可读取本机 `$CODEX_HOME/video-director/account-library.json`（未设置 CODEX_HOME 时为 `~/.codex/video-director/account-library.json`）中的 `profilePath` 与 `indexPath`。这是可选的本地绑定，不是公共 skill 的必备文件；用户指定另一账号时以指定为准，不套用本地默认。没有入口时按现有事实制作，只询问会实质改变作品的信息。

先读账号 PROFILE／profile 核对身份与用户明确选择；通用素材索引在形成本段表达后按需要检索和实际看图，避免把所有资产、旧项目或历史对话塞进上下文。交给制作代理时传绝对入口路径、选用分支、必要素材 ID 与可改范围，并区分必须保留与可选复用。

## 身份、风格与证据分别处理

- 账号资料保存用户明确的姓名、账号名、称谓／性别与公开主页；具体作品可选择不同画风，身份不随画风漂移。
- 人物 IP 保存原始头像、选定角色及可用姿态；生成造型、用户提供形象与真人实拍按来源区别。第一人称作者用已选 IP，其他人物可以代表他人，不能因找到了通用人物就替换作者，也不因统一 IP 将其他角色变成作者。App 头像位、人物叙事和作品署名按各自用途安排，不每镜增加角标。
- 原始图、衍生图、已选／未选／弃用方案分开。加工保留原图，记录来源、用途、状态及必要的许可；字幕图、旧字体子集、混音和整条动画时间轴不自动成为通用素材。
- 真实截图保留身份与内容像素。GitHub／产品页面记录 URL、采集时间与观察范围，使用时核对时效；生成笔记、IP人物和示意界面不能证明实际行为或产品效果。

素材库提供身份、证据和可用资源，不提供固定镜头。先从本片含义决定画面，再选择裁切、分层、姿态和声音；现有资产不合适时自主搜集或生产，不因库里已经有一个人物姿态或道具就强行使用。已认可的本片资产可延续，但共享材料与角色身份不等于反复使用同一构图。作品工程收录实际所用文件与来源，避免只引用临时附件；新衍生资产回收到库并保留与原件的关系。

跨期选材时，区分身份识别、真实证据和通用道具：前两者按准确性与需要延续，通用道具重新判断。合稿时横向看同一素材出现的位置与含义；若相机、书堆、人物或纸条被用于多个不相关命题，应按各段表达重选或生产，不能仅换裁切、颜色、标题和入场。重复承担同一叙事线索、对照或状态变化时可以保留，不设复用比例，也不为求新改造真实证据。

账号库与通用 skill 分开维护。本地路径、个人原图和非公开记录不因更新公共工作流而自动上传；只收与制作有关、已获授权的资产。
