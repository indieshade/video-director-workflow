# 提示词：保留创意自由，明确观看目标

## 有录音的解说视频

> 根据以下现有脚本和录音制作视频。录音保持不变，画幅为16:9。先识别关键命题、转折与结果，为每段设计观众可以观察的变化。文字只承担值得记录的信息和必要指代；情绪与描述优先由画面呈现。先根据内容提出视觉方向，用实际风格帧和动作短样说明材料、字体、构图与动态质地。主动使用适合当前难点的 skills 和成熟库，重点考虑主体、背景、光影及声音如何共同服务内容。制作后查看实际合稿，围绕最影响观看的问题修订。无法由已有录音展开的内容可以提出下次录制建议，当前画面仍服从现有口播。

在这段之后附实际脚本、音频路径、已认可方向和真实素材授权。没有音频时标记暂估时间，不编造听感。

## 同公开提示词的独立创作

> 严格保留以下公开提示词。本次在制作与自审完成前不要读取对标原片、缩略图、静帧或拆解。自主推导观看意图、概念和视觉系统；可查通用理论、工具文档和非对标素材。方向不明确时先给风格帧、动作短样和具体取舍。完成整片及必要修订后锁定源文件和成片哈希，再揭示原片比较。保留所有额外输入差异，提炼可迁移的判断，允许不同设计。
