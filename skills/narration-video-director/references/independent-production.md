# 独立制作入口与交接提示词

用于新作品完整制作、独立重做或同输入对照。把创作任务交给干净上下文中的制作代理，减少历史方案与反复修补的干扰；局部修改优先沿用现有工程。委派服从宿主权限，工具不可用时由当前代理按同一 brief 制作，并如实说明上下文未隔离。

## 简短交接，保留创作空间

主代理从当前材料提炼观看目标、原声与事实来源、已确认风格、必要约束和交付范围。默认交接由任务 brief、明确的风格与素材指导、导演流程责任组成。已选风格的关键内容直接放进制作代理会读到的正文，不以频道名称、风格卡链接或“自行阅读 skills”代替；完整参考仍按需读取。

风格段说明本片的材料与造型如何协调、字形和空间层次如何组织，以及可用的动作语言。它应改变设计选择，不预先指定整片物件、逐秒镜头或效果参数。已选 Vox 摄影剪贴或几何角色与心理隐喻时，沿用下方对应交接段，不叠加另一方向的段落；其他方向按其实际参考和已确认特征重写。风格尚未确定时按选型流程处理，不把主代理临时编出的风格当成用户选择。

输入区分必用素材、可选来源与观察参考。允许自主选材时，把搜集和加工交给制作代理，不预先制作一套带明显构图与隐喻倾向的素材包。用户指定的素材、品牌资产与认可设计照常保留；参考查看范围和盲测限制明确传递。

使用宿主支持的独立上下文机制，不继承完整聊天；提供必要绝对路径及可访问权限，避免只说“素材在前面的对话里”。保留既定模型和工具条件。完整作品通常由一个制作代理负责连续设计，不默认逐镜分派；多条件比较时各组隔离，不互读方案或成片。

主代理负责澄清不可推断的输入、协调必要的方向反馈和最终合稿。制作代理负责理解口播、自主构思、研究选材、画面与声音设计、实现、检查及必要修订；缺少不可推断的事实或授权时向主代理说明。传递用户已经作出的选择，不把主代理尚未验证的方案写成用户要求；制作代理直接执行自身范围，不递归转派。

## 可直接填写的制作提示词

替换方括号为本次实际输入，省略无关项；保留真实约束。风格与动态语言填入正文后再委派，不留下“高级、流畅、有设计感”等空泛要求或只有参考路径的占位。用户要求原样提示词对照时保留实验文本，另记必要适配，不自动叠加本模板。

```text
你是本片的独立制作代理，直接完成以下范围，不再转派。

作品与观众：[主题、制作范围、面向谁、希望观众最后理解或感到什么]
输入：[原声、稿件、事实与必用素材的绝对路径；不一致时的依据]
约束：[项目约定路径、画幅/时长、可改与不可改内容、工具版本、成本/授权及参考查看边界]
输出：[本组独立目录、需要的成品与源文件]

# 风格与素材指导
[已确认风格：写清摄影／插画／图形与必要文字的材料关系、字形角色、版面及光影层次；可以附相关风格卡，但正文应足以指导选择。]
[动态语言：写清此方向可如何移位、保持、替换、展开、变换或交接视线；按本片挑选，不固定构图、物件、镜头数、配色或动作参数。]

# 导演流程
使用 [narration-video-director/SKILL.md 的绝对路径] 及与本片有关的 references，主动选择相关 skills 和成熟工具，按完整导演流程理解口播、研究与搜集素材、自主设计、制作、实际复审和必要修订。框架使用匹配版本的官方指导；按需加载，不要求读完全部参考。自行构思、研究、选材和设计，不必沿用旧作品的构图、隐喻或效果。已有明确创作决定以本 brief 为准；需要用户选型时，先提供能判断方向的实际预览，由主代理协调反馈。

围绕口播含义组织画面，重要画面动作及其含义也应进入声音设计。把相关 skills 和成熟工具用于解决具体难点，保持阅读与听觉空间。完成成片后自行查看实际产物、处理关键问题，再交付成品与源文件路径，以及简短的设计选择、素材来源和未验证部分；导出成功不等于创作完成。
```

这份模板交代任务与质量责任，构图、物件、镜头组织、动效和音色由制作代理决定。除实际要求外，不加入统一镜头数、固定色板、逐秒动作表或必用特效清单；相关 references 在当前难点需要时再加载。

## Vox 摄影剪贴的交接段

用户已选此方向时，默认把下面两段直接带入上面“风格与素材指导”，而不是再缩成“Vox 风格”。可以按已确认分支和素材条件适配；新题材不沿用科普样片或旧片的具体造型、镜头和时序。

```text
这里的Vox式摄影剪贴强调摄影物件、编辑式版面与有形的纸片材料。主体、必要文字、箭头和背景共同形成拼贴；自主研究具体参考，参考画面不直接冒充原创成片。可利用纸边、裁切、印刷色层、接触阴影和克制颗粒组织层次，按内容选择色彩，不固定必须使用某套配色。
文字可以作为剪下的字块、纸条或印刷标题；字幕另用固定公共层。动态可采用有意的姿态保持、纸片替换、展开和分帧移位，也可让必要引导动作连续；不将配音或字幕时钟量化。素材、构图和动作由你决定，没有指定物件、构图、镜头数或预先准备的参考帧。
```

这段指导规定文字存在时怎样处理，不要求增加文字；必要性仍按 [画内文字的选择](text-selection.md) 判断。纸片动作只是此方向的候选语言，制作代理应按语义与注意力决定取舍，不能给所有元素套同一个入场。

## 几何角色与心理隐喻的交接段

用户已选此方向时，把下面两段直接带入“风格与素材指导”，同时提供 [几何角色的造型与表演](geometric-emotion.md) 的可访问路径。它描述画面语言；隐喻、角色和情节由制作代理根据当前口播决定，不沿用旧例的书本或压住后回弹。

```text
本片采用原创几何角色与心理隐喻：以有辨识度的块面轮廓、克制色组和可追踪的面部或形体特征建立角色；让角色与物件的体量、距离、支撑、遮挡及留白承载当前感受。轮廓与负空间先成立，颗粒、纸感和简化明暗随后服务形体，背景也参与构图。不要把任意圆方堆放或添加眼睛当作完成角色设计。画内文字只留必要命题或辨认信息，描述和情绪主要交给姿态与关系，字幕另层；不预设粉紫色板、纸张音色或三维质感。
从口播推导本片的隐喻与动作。决定角色哪里先改变、其他部位如何回应，保持身份、接触点和空间关系可读；按含义选择预备、重心转移、挤压伸展、迟疑或保持，不强制每个动作弹跳，也不把所有内容改成受压后获救。自主搜集、生成或绘制能支持实际表演的素材；需独立运动的部件和关键姿态要实际可用，不能用一张融合插画的整体缩放冒充表演。声音随所选材质、动作和含义设计，也可留白。先用关键姿态与动作短样核对轮廓、受力和隐喻是否成立，再完成与复审本片；具体物件、构图、镜头、色彩和时序由你决定。
```

这是待新题材制作检验的入口指导，不是已验证的稳定配方。相关参考的局部观察与旧试作限制见该参考；不可将旧片表演或此处动作建议说成已完整观看的原作规律。

## 返回与合稿

制作代理在独立目录工作，保留输入、关键设计和来源记录。返回可查看的完整产物及关键选择即可，沿用项目已有分镜和审片文件，不额外编写长篇流程总结。

主代理从实际成片核对 brief、风格与动作语言是否进入主体设计、音画匹配、声音含义与重复感、整体节奏和衔接，再提出具体修订。读过指导或制作记录写了关键词不算落实；看实际素材处理、构图和对象关系怎样随内容改变。需要调整时传递时间位置、观察到的问题与预期改善，允许制作代理重新选择实现；不要退回漫长上下文中逐项叠加参数。已有合适的独立评审者时可复用，按 [创作复审](creative-iteration.md) 执行，不为每次修改强制增派代理。

同输入对照继续保留各组的指导、素材和工具投入差异，不向隔离组透露其他组结果；需要揭示参考时遵守 [独立创作与揭示顺序](comparison-and-calibration.md#先独立创作再揭示对标)。同段 NASA 科普重做中，用户明确认为采用此前第2组提示词的新版更好，因此把其明确风格段保留为当前 Vox 交接默认；素材与随机运行也变化，不能据此证明字数或单项指导的因果效果，也不保证每次产出更好。后续依据新作品的实际反馈删减无收益的指导。
