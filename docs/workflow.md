# 从输入到成片

## 1. 守住已有素材

保留脚本、录音、画幅、时长和不能重录等约束。标题不能替代正文的实际主张。实际配音的停顿、重音和词句起止支持节奏；ASR 时间戳不等于听觉重音。

## 2. 提炼观看任务，再决定媒介

为每个节拍写出：口播表达什么，观众已知什么，这一镜新增什么理解，先看哪里，变化后留下什么。重要、值得记录的命题可用文字；描述与情绪优先通过画面。引用和真实记录要有身份线索。口播说 A，不能因找到精彩素材就让画面说 B。

## 3. 主动发现能力

在主体实现前按镜头难点选择美术、字体、运动、形变、3D、光影、媒体和声音工具。写明“难点 → 工艺选择 → 所用指导/组件 → 要看的证据”。安装或读取 skill 不是效果已经落实的证明。只加载相关指导，不机械调用所有 skills。

## 4. 选型与视觉系统

方向不明确时，用少量实质不同的风格帧、几秒动作短样、关键词及代价帮助选择。参考图支撑材料、字体和构图；连续视频才支撑动作与节奏。画面风格独立于口播内容规划，也不以热门频道名称替代实际设计。

## 5. 关键状态与制作

先做起点、变化、结果；主动作短样验证对象关系、重量、注意力交接和可读停留。声音按动作与段落编排，音乐留白支持口播。框架拥有确定的视频时间；图形、shader 与粒子按同一时间定位，避免任意 seek 改变结果。

## 6. 首版后的创作复审

从观众角度检查完整产物。找最影响目标的问题，提出局部候选，实际比较，采用或回退，再复查接缝。无关键缺陷时可以保留首版，不为迭代轮数而修改。

`creative-review.json` 对应具体成片哈希。校验脚本只检查记录、证据路径和停止决定，不理解画面，也不会证明审美合格。截图、连续观看、听取声音与编码检查分别记录；取不到的感官证据如实保留。

## 7. 比较实验

保存公开原始提示词、额外指导、选型反馈、工具、素材与声音差异。盲测先完成整片自审并锁定源文件和成片，再揭示原片；后续调整另存。比较完整作品的表达、美术、动作、声音和整体节奏，不用复刻精度或与自己旧版的比较替代外部标准。
