# 画内文字的必要性

用于配音驱动的解说视频，尤其是用户反馈文字太多、像PPT的时候。目标是减轻同时听讲、读字与观察动作的竞争；不以删字数量作为质量评分。

## 从视觉命题开始

每个理解节点先写：观众通过观察，应看出哪个对象、关系或变化？不要只把口播缩成标题。再决定口播、对象动作、画内文字分别承担什么。

先核对实际录音中的对象、动作和结论。把抽象口播具体化时，不能改变同期主命题。例如“把数据焦虑转化为行动与验证”并未指定“改视频开头”或“询问试用者是否付费”；即使有真实记录、标注了示例，这些细节也不能自动成为主画面的新解释。选择与口播一致的对象和变化；需要证明当时交流，可贴入原对话截图作为佐证，不强迫观众学习截图里的另一套过程。

## 区分值得记录的知识与正在经历的状态

在这类口播作品中，主画面文字优先承载观众值得带走、复述、引用或应用的信息：定义、必要条件、区别、方法步骤、论点与论据、推理关系、需要精确记录的数据。仅仅是口播重音、主题关键词或情绪结果，不足以成为大标题的理由。

逐句判断它的传播用途，而非只看有没有“焦虑”等词：

| 内容功能 | 主要表达渠道 | 文字判断 |
|---|---|---|
| 定义、概念区别、条件与限制 | 最短完整命题，配合关系图或例子 | 保留使知识准确的主语、关系及条件；孤立关键词可能没有记录价值 |
| 论点、论据与证明关系 | 必要文本、真实证据与视觉推导 | 让观众能分辨主张、依据和推导；不把个人经验升级成公理，不补造论据 |
| 方法或机制 | 先表现对象如何变化，必要时保留步骤关系 | 标注能够复用的关系；示意步骤与原话、真实事实分清来源 |
| 情境、行为与事件描述 | 主体、动作、场景、镜头与前后变化 | 通常不用标题复述；身份、关键数值等无法从画面准确获得的信息按需保留 |
| 情绪、体验与氛围 | 空间关系、速度、重量、光色与落定 | 让状态可感知；不默认把“焦虑”“踏实”“迷茫”等情绪词排成大字 |

同一句里可以同时存在知识和感受。比如“把焦虑转化为可行动、可验证的闭环，我会感到踏实”：过程可用“尝试 → 反馈 → 修订”解释并标明示意；踏实由同一对象获得支撑、停止漂移来表现。它们各有语义到达，不能只删除情绪词而让画面没有变化。

知识句还需要相关性和前提判断。“预案是准备答案，判断引擎是准备问题”具有区别句的形式，但当前观众若不知道两个概念、也没有遇到这个问题，它仍可能突兀。先按 [信息编排与理解连续性](information-staging.md) 决定是否需要引入、后移或删除；若保留，用完整可读的原文或忠实重排，并建立引用身份与来源。只留“准备问题”可能丢失区别的前半部分。“一次尝试”“可验证”等标签按对象识别用途判断，不因它们短或抽象就自动认定为知识重点。

保留前再问：观众会记录这句的什么内容，未来在哪种判断或行动中用到？若只是在告诉他此刻发生什么、主角有什么感受，优先设计画面。这个判断是本类视频的创作取向，不是情绪词永远不能出现的禁令；叙事需要、正在分析的措辞或明确的文字创作按实际用途决定。

## 口播、示意与字幕的对应

区分三类文字：录音实际说出的词句、画面对象必要的标注、为说明机制补充的示例内容。字幕准确跟随第一类；示例不能伪装成录音原话或真实对话记录。给“AI提出个性化的问题”配一句具体提问时，说明它是对话示意。

字幕用实际录音的措辞，核对识别错误；脚本与录音不一致时不直接把脚本覆盖到字幕上。优先复用或生成带词级时间的转写，按语义短句分页，不用均分句长代替语音时间。字幕固定在稳定的阅读区域，避免跟随镜头缩放或在换页时叠出两句。引用内容在画内随口播输入时，先检查是否有必要保留这种重复，以及字幕是否仍能读清。

字幕无法补救画面与口播语义不符。审查时将每个视觉变化对应到原话：它是在显示原话、补充必要信息，还是提供已注明的例子？没有对应关系的文字和动作先修订，再讨论删字和动效。

## 每条文字的删除测试

逐项回答：删除后，观众会失去哪项必要理解？指出具体对象身份、关系、数值、证据或措辞变化；“完整”“丰富”“更像成片”不是保留理由。

| 用途 | 判断 |
|---|---|
| 对象身份、单位或关系 | 不写会误认时保留最短且无歧义的标注 |
| 文字本身被观察或修改 | 保留必要原文，例如开头改写、文件证据；给读取时间 |
| 口播重复或过程总结 | 先由对象变化表达，关系已清楚则删除 |
| 必须记住的准确结论 | 判断是否真的依赖文字；与主动作错开注意力 |
| 来源、示意性质等说明 | 先判断是否影响观众对事实、证据或对象的理解；必要说明跟随相关内容出现，不默认常驻角落 |
| 装饰性章节或风格标签 | 按整片结构判断，局部镜头不默认常驻 |

字幕支持可访问性与无声观看，不能用删除画内文字的理由任意取消已要求的字幕。文字主导的创作、原文证据和数据表可需要较多文字；按任务处理。

上述筛选针对设计进主画面的信息。口播字幕依然准确保留描述和感受，不因为主画面将它们视觉化就删掉；来源和示意说明也各有独立用途。

## 角落信息也需要观众理由

版本号、方案名称、绘图技术、素材处理过程和“这条轨道是一个比喻”等制作说明，通常属于分镜、素材清单或审片记录。不要为了交代工作过程，在左上、右上、左下默认加字；角落有空白不构成添加标签的理由。

判断这些说明时，具体指出观众会因此避免哪种误解，或获得哪项当前需要的信息。证据的日期、样本范围、单位、原话归属等确实影响判断时，随相应证据就近、短暂呈现。明显的概念插画通常不需要额外解释“这是示意”；若画面被误认为真实事件、数值或原对话的风险具体存在，再选择必要的说明方式。

文字与位置独立判断。观看所需的身份、时间、证据说明不能因位于角落就一律删除；制作记录也不能因字号小、颜色淡就自动留在成片。优先让观众观察主体，不让多个边角各自建立一个阅读入口。

## 将文字放到时间上

每个节点只有一个主要阅读焦点；同一对象的改写前后可以组成一个焦点。起始可用同时一至两处文字作为试验预算，出现必要对象标签时调整，不推广成硬上限。写明文字出现、读完、消失和动作接手的时间，不能把所有标签留到结尾。

同一段落不默认常驻标题。保留文字要可读，不能通过缩小字号、降低到看不见或只闪一瞬来宣称文字减少。

## 可审查的最小交接

在已有分镜或审片记录中保存：视觉命题；候选文字的保留/删除及理由；保留文字的出现时间与阅读焦点。简单镜头可以用几句话记录，不强制表格。

审查最终画面：删字后对象关系还成立吗？如果不成立，补最短必要标签或修订对象与动作。不要立即恢复整句说明。检查起始、变化中和落定三个状态，再与实际配音一起评价阅读竞争；没有听取声音时说明证据限制。
