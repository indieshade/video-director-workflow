# 风格、素材配方与模型变化

在用户要求维护风格/素材提示词库、公开作品展示，或检验新模型是否仍需导演指导时使用。只制作当前作品时，选择相关条目即可，不增加全库维护任务。

风格是材料、造型、字体、版面、色彩光影和动态质地的关系。用实际片内静帧及动作展示这些关系，并链接制作输入、工艺、反馈、许可和适用边界。频道名称或风格关键词不能替代实际展示。风格库可以保存失败案例；不同题材的展览不能称为同提示词公平比较。

用户指已有调研库时，以该库的具体外部原作、观察位置和设计语言为选型来源。自有实验或对照作品另存应用记录，不能为了有成片展示而把实验名称反推成调研风格分类。分别记录参考已研究、素材已验证、样片已制作；尚未制作的方向明确留空，不拿不相符的旧片填补。自有混合改编也单独命名。

素材配方从具体镜头角色出发，明确对象、变量、输出需求、所需工具和失败现象。图像生成、程序化绘图、照明与声音配方分别标明用途。按已有作品事后提炼的提示词，不能冒充当时的原始输入，也不能直接标记为已验证。验证需要实际生成、放入相关镜头及对应结果反馈；保留版本与证据，避免只堆关键词或锁死风格。

长期目标是补足当前模型的设计判断，而不是保持流程永远复杂。新模型值得检验时，可比较普通完整 brief、brief 加必要风格/素材卡、brief 加完整流程三种条件。保持素材、工具、交付规格和预算尽量可比，记录搜索、额外用户选择、生成与修订成本和已知差异。沿用同提示词独立创作与揭示参考规则；不凭单次产物作模型排名。

判断收益时先检查任务理解和信息匹配，再看视觉关系、材料字体、动作、声音、全片节奏和意义。跨不同题材、风格确认普通输入已能独立完成相当判断，额外指导无收益或限制创作时，缩短或删除相关规则；局部能力改善只退役相关部分。整个补偿层失去用途时可标为历史方法或归档，出处、许可与复现资料按用途保留。

用户提出长期方向不等于授权无限连续运行或定时监控。每次推进交付具体案例、实际验证和规则取舍；只有明确要求安排未来运行时才另行设置自动化。
