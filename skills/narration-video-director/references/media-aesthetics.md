# 媒体美术：把设计选择落实到画面

用于用户认可解释和节奏，但反馈元素、色彩、字形或素材关系仍缺乏设计感时。已有明确分镜时只修受影响的美术层；它不替代导演分镜、实际配音和审片。

## 先把美术问题落到一帧

按 [从观看感受推导设计](aesthetic-reasoning.md) 从内容与所需感受选择形式。重点比较对象之间的关系：相同色板、字体或材质，换比例、面积、位置与周围环境，观感也可能不同；检查实际画面，不只检查单个素材是否漂亮。

选一帧承担当前语义的画面，写出最大的问题：轮廓过于通用、明暗没有主次、字形没有角色、材质冲突或对象关系不清。色板、参考图和技能数量不是完成依据。调整最影响画面的一两件事，保留现有可用解释。

需要比较方向时，固定口播、字幕、主张和关键到达时间，比较接近最终的关键 PNG，再细化运动。静帧不能证明音画节奏。明确比较中未固定的因素，不把两版样片描述为受众实验。

## 对象与材料

对象应带有本内容的结构：工作稿可以呈现实际波形、影像区和批注位置，证据保持原文，路线可以呈现验证后继续前行的关系。先决定对象由哪些部分组成，关键位置为什么在那里，再画轮廓。适合手工设计的主体不要用大量随机控制点填充。

用不同材料区分作用，例如影像、工作记录、透明批注与证据摘录；只有内容需要时采用。确定光向、边缘锐度、投影尺度和遮挡次序。照片与 SVG 不必同样颗粒化，统一需要的是它们的空间关系。线条的专门检查见 [vector-design.md](vector-design.md)。

## 明暗和色彩

先用大面积背景、主体、次要对象与字幕建立明暗层级，再安排强调色。给每个强调色一个用途，检查最饱和的元素是否真的值得先看。状态变化同时通过形状、位置或标记表达，避免只靠变色。

深底、浅底、平涂和发光按题材选择。深色不自动更高级；细颗粒不保证消除色带；全白全黑也不是普遍禁用色。对比数值是局部可读性的线索，不能单独证明移动、细描边或短时间文字可读。检查字幕背后的实际最差背景，而非只取色板值。

光源、背景和主体共同设计，具体方法见 [光影、背景与特效](lighting-and-effects.md)。检查光来自哪里、照到哪些表面、背景怎样衬托轮廓和故事转折；平面作品可用明暗块面与遮罩表达，不强制写实 3D。辉光、景深与颗粒从属于这种关系，不替代美术设计。

在实际导出的 H.264 中检查渐变、细线、纹理和色边，有这些风险时才增加低码率样段或平台观看。平台重编码没有实际检查时明确未验证。不要为验证任意理论主动上传用户视频。

## 中文字体与阅读

把画内重点、对象标签、原文证据、字幕分别指定角色。比较中文实际字形的骨架、重心、笔画对比和字面大小；字体名称或“衬线配无衬线”公式不能替代样张。选择环境中可用、有中文覆盖的字体，保存素材来源；需要分发时检查许可证。局部子集必须覆盖实际文字，改稿后复查覆盖和载入。

先按 [text-selection.md](text-selection.md) 区分值得记录的知识与需要感受的状态。对已选定的画内文字，用字形、尺度及揭示方式表达层级；描述或情绪的重点优先通过动作、空间和落定表现，不因它是口播重音就自动排成大字。字幕保持稳定，密集句子不逐字弹跳；文字主导的作品可以设计字形表演，仍保留必要阅读时间。原文证据需要能读，不用排满原截图作为证据的替代。减少阅读负担优先删去重复信息，不把重要字缩到不可读。

给每项文字写出出现、完全可读、开始退场的时间。进入和退出阶段不算完整阅读时段；字形落定后仍需稳定停留。中文按真实语义块、字符密度和目标观看尺寸检查，不直接套英文 words/minute。时间过短时先缩减画内文字，字幕保留实际口播。

动画尽量不反复触发布局重排：用遮罩、透明度和 transform 表达出现，避免连续改变字号、字距和容器宽度使行文跳动。重点字的变化与字幕时机独立核对，不以 ASR 时间推断声学重音。

## 参考与 skill 的取舍

评价一个新 skill 的实际正文：它是否改变对象设计、材质、构图、字体或验证方式？是否只是泛泛要求“高级”？是否把默认深色、固定色数、英文词速、图片数量或外部服务当成万能要求？安装前确认范围和必要依赖，只应用与当前任务相符的部分。

- [Anthropic canvas-design](https://github.com/anthropics/skills/tree/8a1541c4a3ffa5a20a5a91de0dcf3f0bab1d1ef4/skills/canvas-design)适合静态关键画面：先说明空间、材料、尺度和层级，再做 PNG，第二次精修优先修关系。不是视频剪辑、动作和声音的指南。
- [Kinetic Typography](https://github.com/SkillMedev/skills/blob/a28c4ce9366b5a8540577bed8f70b6a60f8fde27/skills/kinetic-typography/SKILL.md)可参考稳定阅读窗口和文字动效的节制；中文阅读和字幕处理按实际口播适配，不照搬英文计词公式。
- [Motion Color and Light](https://github.com/SkillMedev/skills/blob/a28c4ce9366b5a8540577bed8f70b6a60f8fde27/skills/motion-color-and-light/SKILL.md)可参考编码后的色彩检查；其深色和发光偏好只适合部分方向，不能作为质量通则。
- [Moodboard Builder](https://github.com/SkillMedev/skills/blob/a28c4ce9366b5a8540577bed8f70b6a60f8fde27/skills/moodboard-builder/SKILL.md)可借鉴给参考标注具体用途、区分情绪方向与制作方式；已有作品反馈时不强制扩大成品牌访谈和固定数量的参考收集。

这些外部资料是方法来源，未安装时不称为已调用 skill。新方法用实际画面及用户反馈校准，不承诺安装即提高审美。
