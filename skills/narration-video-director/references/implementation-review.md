# 实现交接与审片

## 技术交接

实现者需要视觉系统、配音文本、分镜、素材位置和时间证据状态。没有实际音频时先做时长可调整的样段，不把暂估秒数当成最终同步结果。

| 需求 | 候选 | 注意 |
|---|---|---|
| 图表、箭头、过程或形状变化 | SVG / Remotion 路径工具 | 先保证关系正确 |
| 手绘笔触与填充 | Rough.js | 固定 seed 保持重绘稳定，时机由时间轴控制 |
| 人物、对象、环境拼贴 | 图像或视频素材 | 拆层、透明边缘和构图优先，不只缩放整张图 |
| 空间、结构、相机运动 | Three.js / React Three Fiber | 用 Remotion 兼容集成，状态由帧驱动 |
| 旁白、字幕和声音 | 音频与字幕工具 | 使用实际时间码，保留修订能力 |

实现前交接关键画面和主体素材的实际处理，不只交接工具名与抽象节拍。涉及素材不足、文字主导或动作机械时，分别读取 [视觉解释与素材制作](art-direction.md) 和 [动作设计与声音](motion-and-sound.md)。

Rough.js 提供绘图质感，不替代分镜；引入 3D 应有可指出的表达收益。

工具默认优先复用成熟实现。涉及依赖选择或手写通用能力时，按 [工具复用与依赖选择](tool-selection.md) 从镜头难点落实到具体库、兼容版本和实际输出。

制作或修订线条、SVG 主体与标注时，按 [线条与 SVG 设计](vector-design.md) 交接本场景需要的笔触、语义和层级。检查运动中的端点与遮挡，以及导出后细线、虚线和纹理的表现；不以添加滤镜、减细线条或使用 Rough.js 作为审美通过的依据。

## 官方技能与版本

选择环境中一套匹配项目的官方 Remotion skills：`remotion-best-practices` 为入口，按需要加载创建、markup、captions、interactivity、Studio 和 rendering。不要叠加同名旧包与新版插件。依赖和既有实现是判断版本的依据，不自动升级项目或安装工具。

本技能不复制易变的 API 代码。实现时核验：

- [Remotion skills](https://www.remotion.dev/docs/ai/skills)
- [官方交互规范](https://github.com/remotion-dev/skills/blob/main/skills/remotion-best-practices/remotion-interactivity/REFERENCE.md)
- [Remotion 3D](https://www.remotion.dev/docs/three)
- [Rough.js seed](https://github.com/rough-stuff/rough/wiki#seed)

## 可编辑性

按当前版本规范，让独立调整的主体、文字、场景和关键帧具有独立编辑目标及名称。在 Studio 实际选中并修改一次关键元素，确认能保存到代码。

检查保存后的源代码、刷新后的属性值及相关导出，记录具体对象和修改项。仅能选中、显示边框或出现“可编辑”声明，不代表修改已持久化。将镜头组件直接注册为独立 composition 并在主时间线引用同一组件，便于修改回到成片；这不能自动保证自定义路径和计算属性都可面板编辑。

复杂 Rough.js 路径、程序化布局和 Three.js 内部状态不必都支持拖动；暴露有用参数，说明哪些由代码修改。数据驱动图表可以整体管理，不为可编辑性破坏准确性。

时间使用单一真值：音频锚点或项目已有时间数据。分镜记录意图，代码实现实际时间；变更后同步受影响的分镜，不保存两套互相冲突的最终时间。

## 审片

记录实际发现：`时间 / 元素 → 问题 → 修改 → 复查结果`。没有问题就说明检查范围，不凑清单。

按交付范围选择检查：

1. **分镜**：画面说明对应意思，素材可实现，估时与实测分开。
2. **静帧**：目标画幅下主体、文字、图表及遮挡可辨认；检查构图、素材处理和视觉解释，不能仅以文字读得清就宣称审美通过；不由此宣称动画与声音通过。
3. **带声连续播放**：重点到达与配音锚点一致，观看与阅读不竞争，接缝自然，声音可懂；检查动作的动机、速度、跟随和保持，而非只检查帧数能推进。
4. **交互**：需要人工精调的元素能在当前 Studio 编辑并保存；边界明确。
5. **导出**：请求导出时核对尺寸、FPS、时长、音轨，播放修订片段和接缝。

预览掉帧或卡顿时记录环境和位置，必要时检查短片段导出，不直接判定源视频有错。只请求分镜时不要求渲染。

先修最影响理解或节奏的一两处，再复查相关片段及接缝；存在全片影响时才扩大检查。

技术审阅与创作审阅分别记录。用户指出未达到参考风格时，把该方向记为需重做；已验证的编译、同步或页面运行仍可沿用，但不再将原样片作为美术通过的依据。
