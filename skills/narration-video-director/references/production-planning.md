# 制作规划与能力调度

用于新制作、重做视觉方向或已安装能力没有进入作品的情况。主动调度是制作的一部分，不能把库和 skills 当成用户指出问题后才查阅的资料。已有局部设计成立时，只处理受影响范围。

## 先守住实际输入

从 brief 提取必须表达的内容、可改与不可改的素材、画幅、时长、声音、工具和版本约束。保留同提示词比较的实际文本，另记我们的创意选择与额外指导。无声、纯 2D、禁止网络素材或保留 pinned versions 的任务，按这些条件选择能力；工具多不能成为违反 brief 的理由。只有制作范围需要时才进入实现或导出。

新作品默认先用 HyperFrames，按制作、GSAP 编排和 CLI 操作的实际需要选择当前版本的官方指导。现有项目局部修订不自动迁移，明确的工具要求优先。Remotion 指导只在实际使用它时加载；不能因过去的默认工具继续忽略现在的制作入口。

独立制作按 [制作入口与交接提示词](independent-production.md) 划分主代理和制作代理的职责。交接正文保留目标与约束，并直接带上已选风格的材料、字形、版面及动态语言；按该参考的默认模板组织，不把关键指导压缩成频道名或一个 skill 路径。分镜、选材和具体表现由制作代理形成，已有用户认可的决定继续保留。详细指导按难点读取，交接不复制整套流程正文。

## 观众最终状态与标志性画面事件

先在已有 brief 或分镜中写清：谁在看、起初知道或感到什么、结束时希望发生什么变化。知识、感受与行动按本片目的选择，不要求同时满足，也不默认增加 CTA。用这项最终状态判断开头承诺、内容取舍和结尾是否兑现；它不能成为改写既有口播主张的理由。

在方向设计中提出少量值得观众记住的画面事件，数量随片长与内容决定，不固定要求三个。先用对象、行为和状态变化描述，不用特效名称代替创意；例如“挡住人物视线的便签逐渐让出一条可走的路径”，再决定材质、运动与实现。说明它对应哪段内容、为什么值得强调，以及前后的铺垫与保持。隐喻不额外创造事实，也不把这个例子的造型作为以后通用模板。

创作方向尚未明确时，按[创作方向选型](comparison-and-calibration.md#创作方向选型)用实际关键画面、动作短样和关键词展示候选，再展开完整制作。让预览暴露标志性事件的主体、变化或结果；核心表演尚未成立时先修设计，已有充分证据时直接复用，不另加审批或独立样段。先区别原始要求、代理提出的形式和用户选择；用户选型与代理自审分别承担偏好校准和质量检查，不能互相代替。

节奏、素材和转场按上述观看目标选择。快切、匀速、静止保持、重复构图、照片与真实截图都可服务表达，不将某类 showreel 的偏好变成跨风格禁令。配音作品以语义、重音与停顿为首要锚点，音乐支持段落；音乐主导的作品再按音乐组织。静音检查用于发现视觉关系缺口，不要求画面独立复述全部口播。

## 让视觉研究改变设计决策

新作品或显著重做时，从 brief 中挑出决定质量的视觉难点，按 [从观看感受推导设计](aesthetic-reasoning.md) 建立所需感受与设计关系，在铺开主体实现前主动寻找并实际查看相符的画面或动作。已有充分参考时复用；缺什么再查什么，不固定参考数量或强制多方案。理论用于理解机制与适用条件，视觉作品用于观察具体处理，技术文档用于选能力，各有用途。成片禁止外部素材时，仍可查看参考研究原理，最终实现继续遵守素材与工具约束。

用户要求先不看对标时，遵守[先独立创作，再揭示对标](comparison-and-calibration.md#先独立创作再揭示对标)。对标原片及其衍生视觉在整片自审、版本锁定前不可读；能力发现与通用原理研究继续进行，不以“必须找参考”为由突破该限制。

新美学方向的采样、参考板和数据筛选按 [美学风格选型与表现数据](style-selection-and-performance.md) 处理。把来源的传播条件、实际画面观察和采用的设计判断关联起来；未看过片内画面或没有可比数据时保留限制，不补写“高流量风格已验证”。

研究问题从当前选择为何失效出发，例如注意力竞争、轮廓难以辨认、动作没有重量或效果缺少层次，而非只搜风格名称。已理解的机制可以直接应用；不熟悉或反复失效时查原作者、论文或官方教学，再形成可在本片验证的设计假设。保留必要出处，区分来源结论与我们的应用推断；不要求每镜联网或搜齐一套理论。

把研究融入现有 `style.md` / `storyboard.md`，用短记录说明：

`观看意图与当前问题 → 参考机制及来源位置 → 本片采用或舍弃的设计与代价 → 关键帧/动作样段的观看证据 → 必要修订`

说明为何改变原有选择，或为何已有选择成立。不要先写完方案，再补几条参考链接替它背书。动作参考要看变化过程；静态图、字幕、README 或教程标题不能证明动作时序。未能查看的内容保留为待核验，不据此声称已应用。

审美用语需要转成可观察的结果。例如“有力量”可落实为准备姿态、释放时的尺度与时长、接触或受光对象的响应；“干净”可落实为重要轮廓之间的空隙与注意力主次。具体实现随题材选择，不固定为某种粒子、构图、效果或数值。参考与 brief 冲突时说明舍弃理由，独立创作不照搬其造型或动作。

先制作足以判断方向的实际关键画面或主动作，允许为样段写局部代码。证据推翻方案时修改设计后再展开整片；色板、工艺列表和书面承诺不能代替这一步。合稿发现同类问题时回到相关设计选择，不只加装饰或把已知核心缺陷留给用户发现。

## 在主体实现前发现相关能力

检查当前环境提供的 skill 名称与描述、项目依赖、已有组件及选中技能的入口。从镜头难点找能力：视觉解释与美术、字体与阅读、关键姿态与编排、路径或形变、光影与合成、媒体与声音、预览或导出。读取与本片有关的正文和必要 reference；同名技能按范围与版本选一套。没有发现合适能力时再查官方资料或相符的公开实现，不伪称未读的资料已经应用。

把最影响作品的能力落实到分镜，而不是只列工具名称。沿用现有文档，用简短记录说明：

`镜头难点 → 设计/工艺选择 → skill 与实际 API/组件 → 应检查的画面或动作`

例如，高速对象移动可评估曝光式动态模糊；重点文本落定需要清晰稳定；可追踪形变需要轮廓对应与中间姿态。景深、辉光、颗粒、拖影和 3D 均按表达收益选择，不作为高级作品的固定套餐。设计主体、构图和动作关系仍由创作者负责。

质感设计从 [光影、背景与特效](lighting-and-effects.md) 确定主体与环境的关系。沿用风格说明和分镜记录重要光源及其影响、背景层级、特效作用对象与到达时间；关键画面检查明暗和材质，动作样段检查联动与衰减。把光效放到视觉设计和编排中，避免整片结束后才统一覆盖一个滤镜。

含声音的作品同时按 [音乐、动作与声音空间](sound-design.md#在分镜时按动作与含义选声) 把选声落实到重要画面事件。任务已授权委派时，将声音设计连同口播、画面动作、风格、成本与工具约束交给制作子代理，保留其搜集、加工和选择声音的空间，不预先限定一套通用音效包。交付应包含实际混音及关键声音用途、锚点、来源和未完成的听审范围；主代理合稿时检查动作与含义的匹配、重复感及转折收束，不只检查是否存在音轨。

## 让工具承担通用能力

按 [工具复用与依赖选择](tool-selection.md) 优先复用成熟能力。保留明确的版本和帧驱动契约；做兼容性核验，避免套用新 skill 中旧项目不存在的 API。素材、缓动、噪声、形变与时间轴在任意帧定位时应稳定。不能用实时运行的网页动画替代可定位的视频动画。

视觉方向先用接近最终的关键状态检查；最难的动作先做能暴露轮廓、遮挡、时序及合成问题的片段，然后完成整片。已有充分设计不重复探索，难度低的镜头不强制另做样段。

## 执行与证据闭环

完整制作与显著重做按 [创作复审、迭代与停止依据](creative-iteration.md) 在开工时明确本片重要质量目标，首版后安排创作复审，保存修改候选的取舍和停止依据。需要检查执行状态时使用其中的记录校验器；它检查当前文件与决定的对应关系，不证明审美通过。

用于制作与显著重做；纯讨论、分镜交付与局部修订按原范围处理。沿用已有文件和产物，避免额外建立打卡表。先选定最影响当前作品质量的难点，把希望观众实际看到的结果写进分镜，然后按制作阶段回查：

- **关键画面**：在铺开整片前，把主体造型、构图或关键姿态做成接近最终处理的画面。按目标观看尺寸检查主次、轮廓和材质，记录最薄弱的一处及修订；只有色板、文字说明或可运行的占位物时，仍属于待设计状态。
- **主要动作**：对最难或最重要的动作，检查中间姿态与必要接触关系。例如“探身、下梯”需要看得到观察、抓扶、踏步和重心变化，通用步态叠加整体位移不能直接算该动作完成。其他题材按自身的关键关系检查，不把人物案例套到图表或所有镜头。
- **交付审片**：从分镜回查本片重要承诺，记录 `具体承诺 → 实际帧或片段 → 判断与修改 → 修订后的复查`。看过技能、代码里存在组件、播放帧数推进，只能证明相应读取或接入状态。创作判断需要可见画面和动作证据；未完成的观看检查明确标为未验证。

交付审片还要回到原始 brief，不能只证明自己的分镜已经实现。自选概念可能将“高能量作品集”收窄成精致但温和的材料展示，也可能将“可信解释”扩成炫技。结合整片检查尺度、注意力范围与变化强弱是否服务原要求；最影响整体的一处仍不足时修订。这里检验表达是否成立，不要求所有题材增加变化、满屏或快切。

已观察到的核心缺陷仍妨碍当前目标时，在授权范围内继续修订受影响的设计与动作。不要只修编译、遮挡或格式问题，就将薄弱的造型和表演当作已通过。明确请求草稿、受限制作预算或尚缺关键素材时，可以交付相应阶段，并准确说明状态。审美判断不能用文件存在、固定分数或检查项数量自动证明。

这些阶段由代理自审与修订，只有真实缺失的输入或会改变创作方向的选择才需要用户参与。用户的重复提醒不应成为开启审查的条件；后续反馈作为校准，不承担代替代理执行流程的职责。

## 动态模糊与后期处理

按 [光影、背景与特效](lighting-and-effects.md) 选择处理对象和实现；使用 Remotion 曝光组件时再读匹配版本的官方 motion-blur guidance。区分帧内曝光采样、风格化拖影、景深与普通柔化。选择应对应实际运动和视觉角色；阅读文本、证据与落定姿态保持可辨认。明确处理层级，避免不必要的全画面处理。

曝光采样必须取得不同子帧时间的实际姿态：检查时间是否传到被采样对象、整数缓存是否误用、随机是否固定、场景切点是否采入错误内容。Remotion 中还要检查 `useCurrentFrame()` 是否在被采样的子组件内；HyperFrames 中检查适配器是否允许所需时间精度及实际逐帧输出。多个帧叠层会增加成本，部分实现还会改变透明度或色彩；检查实际输出，不能只证明 wrapper 存在。需要新浏览器能力时核对预览和导出兼容性，并保留合适的降级方案。

## 审片时回查落实

对重要选择确认三件事：指导被读取并改变了具体决定；相应能力已进入实际镜头；输出达到了预期用途。区分读过、已接入、技术通过、模型视觉观察和用户确认。只对当前重要难点做这种记录，不制作逐文件打卡或全技能覆盖率。

效果有争议时，比较同一动作开启/关闭效果后的连续播放与关键帧，检查轮廓、阅读、色彩和注意力。差异不清楚或妨碍理解时允许减弱或删除；不用特效掩盖形状与节奏问题。同提示词新作品用外部原片检验完整设计质量，自己的前后版仅用于定位局部改动。不同上下文与工作流仍需记录，不能把一次创作当成模型普遍排名。
