# 示例：生成速度与表达判断

虚构的约 20 秒解说样段，演示分镜粒度。没有真实配音、素材或成片。所有秒数为暂估；设计内部检查不能升级为节奏播放确认。

本例是关系图交接粒度的示范，不是 Vox 美术或动作品质的标杆。不要将其暖白背景、卡片、箭头和文字标注默认复制到新题材；新视觉方向按 [视觉解释与素材制作](art-direction.md) 建立关键画面。

## 配音草稿

“AI 能很快生成一段动画。但它还得决定：这一句该让观众看见什么。讲比较，就把两个方案放在同一尺度上；讲过程，就让变化按顺序发生。动作的时机，最后跟着真实配音调整。”

主张：生成速度与视觉表达需要分别处理。让观众理解比较、过程和音画校准三个制作选择，不预测传播效果。

## 视觉系统

- 暂用 1920×1080；竖屏需重排构图，不直接裁切。
- 暖白 `#F4F0E8`、近黑 `#242424`、深红 `#B83A32`。这是示例的新选择，不是教程色值。
- 字体使用环境中可用且覆盖中文的无衬线字体，区分主标注与辅助标注。
- 本例使用 SVG 图形和简洁卡片，Rough.js 只做强调线，无需照片与 3D。
- 主体错开出现，结果停稳，同一对象跨句保留。
- 配音保持清晰，BGM 可先省略。比较结果可试一个轻提示音，再按实际播放决定保留。

## 节拍分镜

| ID / 暂估区间 | 配音 / 理解任务 | 起始 → 动作 → 可读结果 | 语义锚点 / 停留 | 实现与声音 | 衔接 |
|---|---|---|---|---|---|
| B01 / 0–3s | AI 能很快生成一段动画。呈现生成过程 | 空白画布 → 三个元素依次出现 → 简洁完整场景 | “生成”启动，“动画”前形成画面，句尾保持 | SVG 卡片，暂不加音效 | 保留画布和元素 |
| B02 / 3–8s | 但它还得决定：这一句该让观众看见什么。突出表达选择 | 完整场景 → “但”处停止运动，淡化两项 → 单一主体与“看见什么”标注 | 停顿后出现标注，保持到问题说完 | SVG + 轻描线，无额外装饰 | 主体移左，让出说明空间 |
| B03 / 8–12s | 讲比较，就把两个方案放在同一尺度上。显示可比较性 | 两方案 → 共同基准线绘出，对象并排对齐 → 清楚的共同基准 | “同一尺度”时线完成，对象保持 | SVG，相同大小；不虚构统计差异 | 基准线变成过程轨道 |
| B04 / 12–16s | 讲过程，就让变化按顺序发生。显示先后 | 初始状态 → A、B、C 依次连接 → 完整顺序图 | “按顺序”时依次到达，结果保持 | SVG 路径，无需 3D | 顺序图收束成时间轨道 |
| B05 / 16–20s | 动作的时机，最后跟着真实配音调整。解释同步 | 示意轨道 → 声音锚点与动作标记对齐 → 两标记落在一处 | “真实配音”显示声音标记，“调整”处对齐，句尾停稳 | SVG，标注“时间示意”，不用伪造的实测波形 | 稳定结果结束，无强制 CTA |

语义锚点优先于估计秒数。真实配音更长时，按停顿、重音和理解时间重排，不为凑 20 秒机械加速。

## B03 的动作粒度

1. “讲比较”：两方案错开出现，避免同时争夺注意力。
2. “就把两个方案”：将对象移到共同基准附近，保持身份可辨认。
3. “放在同一尺度上”：基准线完成，对象对齐。没有数据，因此不加虚构高度、百分比或胜负颜色。
4. 句尾停稳，观众看清基准关系后再进入过程图。

这四步说明视觉事件顺序，实际配音取得后才算准确起止帧。

## 交接状态

- 已明确：元素、起止状态、锚点、实现和衔接；预计无需外部素材采购。
- 待取得：实际配音、最终画幅、可用字体。
- 待验证：静帧、连续音画播放、Studio 参数保存、请求导出后的 MP4。
- 尚无证据：技能质量增益，以及与参考片的成片接近程度。
