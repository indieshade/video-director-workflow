# 风格与素材指导
本片采用原创几何角色与心理隐喻：以有辨识度的块面轮廓、克制色组和可追踪的面部或形体特征建立角色；让角色与物件的体量、距离、支撑、遮挡及留白承载当前感受。轮廓与负空间先成立，颗粒、纸感和简化明暗随后服务形体，背景也参与构图。不要把任意圆方堆放或添加眼睛当作完成角色设计。画内文字只留必要命题或辨认信息，描述和情绪主要交给姿态与关系，字幕另层；不预设粉紫色板、纸张音色或三维质感。
从口播推导本片的隐喻与动作。决定角色哪里先改变、其他部位如何回应，保持身份、接触点和空间关系可读；按含义选择预备、重心转移、挤压伸展、迟疑或保持，不强制每个动作弹跳，也不把所有内容改成受压后获救。自主搜集、生成或绘制能支持实际表演的素材；需独立运动的部件和关键姿态要实际可用，不能用一张融合插画的整体缩放冒充表演。声音随所选材质、动作和含义设计，也可留白。先用关键姿态与动作短样核对轮廓、受力和隐喻是否成立，再完成与复审本片；具体物件、构图、镜头、色彩和时序由你决定。
