# 提示词：保留创意自由，明确观看目标

## 有录音的解说视频

> 根据以下现有脚本和录音制作视频。录音保持不变，画幅为16:9。先识别关键命题、转折与结果，为每段设计观众可以观察的变化。文字只承担值得记录的信息和必要指代；情绪与描述优先由画面呈现。先根据内容提出视觉方向，用实际风格帧和动作短样说明材料、字体、构图与动态质地。主动使用适合当前难点的 skills 和成熟库，重点考虑主体、背景、光影及声音如何共同服务内容。制作后查看实际合稿，围绕最影响观看的问题修订。无法由已有录音展开的内容可以提出下次录制建议，当前画面仍服从现有口播。

在这段之后附实际脚本、音频路径、已认可方向和真实素材授权。没有音频时标记暂估时间，不编造听感。

## 独立导演与制作代理

使用[制作入口的双代理可填写模板](../skills/narration-video-director/references/independent-production.md)，把任务信息与当前选中的风格段直接填入正文；不要只传风格名称或要求读完所有skills。导演统一视觉与声音意图，制作方依据实际关键状态实现，二者使用获准的干净上下文机制。主代理提供必要原声和约束并协调交接，不提前制作带有构图答案的素材包。保留宿主模型设置；无法隔离或用户指定其他分工时如实记录。

摄影剪贴、几何角色和极简UI各有交接段，按本片选用，不全部叠加。导演在分镜时设计关键镜头的连接关系，再交制作方按机位、轮廓、方向或意义准备相邻素材；按内容选择匹配、直切或保持，不统一套转场。声音首版完成，依动作与含义安排信息到达、转折、收束及留白。制作方自查后交导演从实际成片取证合稿，主代理核对交付。历史新题材输入见[摄影剪贴](../gallery/jfk-collage/prompt.md)和[几何角色](../gallery/fear-itself/prompt.md)，它们保留当时的分工与条件，不冒称已采用后续更新。

## 同公开提示词的独立创作

> 严格保留以下公开提示词。本次在制作与自审完成前不要读取对标原片、缩略图、静帧或拆解。自主推导观看意图、概念和视觉系统；可查通用理论、工具文档和非对标素材。方向不明确时先给风格帧、动作短样和具体取舍。完成整片及必要修订后锁定源文件和成片哈希，再揭示原片比较。保留所有额外输入差异，提炼可迁移的判断，允许不同设计。
