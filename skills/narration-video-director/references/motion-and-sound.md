# 动作设计与声音

用于动作样段、机械插值或声音设计的修订。把动作作为对象的行为来设计；缓动决定速度曲线，完整动作还需要动机、路径、关键姿态、时序与停留。

## 将动画原则用于当前画面

迪士尼十二法则提供可用的观察维度，不要求每镜使用全部原则，也不把所有图表、证据或标题拟人化。

按 [从观看感受推导设计](aesthetic-reasoning.md) 判断所需的运动性格。Timing 关心发生与到达时间、持续和停留，spacing 关心相邻姿态间的距离变化；两者一起决定我们如何读出速度、重量和情绪。相同起止姿态与总时长，可以因启动、加速和制动的位置而显得不同。先看实际姿态与变化，再判断曲线，避免把流畅、自然或弹性当作唯一目标。

| 维度 | 解说视频的设计问题 | 应避免的套用 |
|---|---|---|
| Staging / 调度 | 什么先被看见？移动期间有谁在竞争注意力？ | 所有元素同时动 |
| Anticipation / 预备 | 观众能否在主要变化前察觉动作即将发生？ | 每次都反向移动或停顿拖时长 |
| Pose to pose / 关键姿态 | 起点、转折、重点到达和结果姿态是否成立？ | 只指定两坐标就让插值决定整个动作 |
| Slow in/out / 缓入缓出 | 对象如何起动、制动，重量与目的是什么？ | 全局替换成同一种 ease 或弹簧 |
| Follow through / Overlap | 主体先停，哪些附属物稍后落定？ | 所有属性完全同步 |
| Arcs / 弧线 | 人、实物、视线或隐喻对象需要怎样的路径？ | 数据关系本来是直线也强行弯曲 |
| Timing / Secondary action | 重音到达在哪里，次要动作如何支持它，结果留多久？ | 每句话固定相同入场和停留 |
| Squash/stretch / Exaggeration | 哪种弹性或夸张能表达材质与情绪？ | 将纸张、截图、文字都做成橡皮 |

Appeal、solid drawing 等同样提醒检查轮廓、体积与设计吸引力；复杂角色表演再展开完整原则。不把原则数量作为质量评分。

匀速扫描、稳定播放指示或某些数据绘制可以使用线性运动；机械、冷静或不可阻挡的运动也可以有意保持匀速。物体位移与转向根据其性格安排加速、制动和路径；淡入、突变或跳切也可能是合适的呈现方式，但不自动完成需要表演的动作。弹簧的弹性应服务材质或情绪，稳定的信息图也可以用无过冲缓动。

## 重点动作的交接

只细化承担重要语义或决定观感的动作，常规片段沿用已经验证的语言。下面提供检查关系的顺序，按需要选择阶段，不要求每个对象执行完整链条：

`为什么动 → 预备 → 主动作与路径 → 重音处重点到达 → 附属物跟随 → 可消化的保持 → 下一动作接手`

预备可以让观众预计方向、察觉施力或等待释放；慢而清楚的变化可弱化它，突然发生的事件可有意省略。跟随和错位响应交代部件关系，不必让所有属性各自延迟。保持给结果观察时间，循环或持续过程可以由下一个变化承接；不能为了凑阶段拖慢叙述。需要蓄力、接触或结果的 brief 仍要真实呈现这些要求。

例如，让注意力从一堆结果转到一个可处理的问题：先收拢视线，选中一个对象；主体沿明确路径进入工作区，旧对象被降权；附属线条稍后跟上；在口播“具体”处落定；保留时间看清这一次改变。不要让 AI 标志挥一下就把所有问题神奇地解开，也不要把“转化”只做成抽象标题替换。

新作品默认由 HyperFrames 控制视频时间，GSAP 主/子时间线编排关键姿态、停顿、错峰和联动；只读取缓动函数不等于完成动作编排。Remotion 项目按当前官方 skill 由帧数驱动关键帧或 GSAP 时间线。复杂路径、Rough.js 或 3D 可由代码计算，但轮廓、姿态、种子和过程应稳定。先检查几个关键姿态，再连续播放检查 spacing、动作衔接与时长。曲线图的漂亮形状不是最终验收对象。

光效、烟尘、拖影等属于动作编排的可选层，按 [光影、背景与特效](lighting-and-effects.md) 设计预备、峰值与消退，并与受影响的主体和环境联动。不能用后期模糊掩盖没有设计的中间姿态。

## 从整体变换走向形状表演

主体设计已成立、运动却主要依赖整体位移、缩放或旋转时，先找到一个具体驱动：哪里先受力或改变，哪里随后响应，形状最终为什么成为另一个姿态。可以让前端带动后部、折痕逐段传递或部件依次释放；刚性物件与准确数据不强加柔性变形。先选择有表现力的中间姿态，再决定速度曲线，避免用连续转圈掩盖缺少动作内容。

线、带和有尾部的对象沿路径运动时，分别设计领先点、跟随部分和材质变化。领先点的路径与切线、后部的跟随距离或延迟、宽度与扭转的到达可错开；它们应让观众看出同一次运动的关系。结果姿态留出观察时间，下一次释放或离场再接手。不为增加复杂度让全部参数一直振荡。

形变尤其要检查途中轮廓。起止路径的参数方向、绕行次序、端点和关键转折需要对应；局部延迟后，切线应来自实际变形后的曲线，而非直接混合两条原始切线。端点看起来漂亮不代表插值途中成立。出现缠结、扭断、细长尖角或错误遮挡时，先修对应关系与中间姿态，再考虑拖影和材质装饰。

[15 秒 showreel 的局部对照](motion-craft-case.md)记录了一次从整体旋转改为逐段展开的制作实验。用户审阅后仍明确指出与参考差距极大；它是失败校准记录，不是成功范例，也不是此类形状必须展开的规则。

## 同提示词下的独立创作质量

用户要求与某个模型在同一套提示词下达到接近的美感和设计感时，按独立创作理解任务。参考片提供质量标准，主体、风格、构图和动作方案可以不同；相似轮廓、同一轨迹或逐镜重建不是验收要求，也不是后续创作的前置条件。

保留实际提示词和其中的内容、时长、画幅、必用素材及工具约束。记录已知的输入差异、额外 skills 与人工指导；公开提示词缺少系统上下文或原始工程时，说明比较范围。不能用补写的详细分镜冒充原提示词，也不能把作品对照称为受控模型排名。

从提示词建立自己的视觉概念，再选择有表现力的关键画面和动作关系。重点明确主体轮廓与负空间、颜色和字体角色、材质与光影、视觉焦点，以及跨镜头的变化逻辑。先解决设计中最薄弱的选择，再用成熟库实现；库的数量、动作数量和技术复杂度不作为完成度依据。可比较少量不同方向并择优，不把方案数量变成固定流程。

用关键状态和整片连续播放判断：画面是否有吸引力，造型与曲线是否经过推敲，配色和字体是否协调，主次是否清楚，运动是否有性格和层次，衔接与收尾是否完整，以及整片是否形成一致又有变化的视觉语言。把差距落到我们作品的具体时间、元素和修改，不因设计不同就判为失败，也不因比自己的旧版更好就宣称接近参考。技术通过、静帧观察、连续观看和用户反馈分别记录。

只有任务明确是技法复现或用户要求重建时，才按源片或源码保持关键姿态、时序与联动参数，检查复现精度和许可。阅读完整组件与依赖素材能帮助理解工艺；这种练习的成功不证明同提示词下的独立创作质量。

## 声音是制作的一部分

需要选择配乐、加强音效或调整混音时，读取 [音乐、动作与声音空间](sound-design.md)，从当前作品的情绪、动作关系与段落结构推导素材及处理，不将声音仅作为画面完成后的装饰。

| 任务 | 工具与交接 |
|---|---|
| 已有口播 | 先听实际素材；保留表达、停顿与呼吸，标出需要处理的噪声、截断、响度和动态问题 |
| 配音、音乐、音效生成 | 选择实际可用的生成工具或素材来源，写声音的用途、情绪、材质、时长及权利/成本条件；已有真人录音不自动换成 TTS |
| 音频处理和测量 | FFmpeg 或现有音频编辑工具负责剪切、格式、必要的淡变、响度测量/处理及混音；不将 FFmpeg 当成通用语音或音乐生成模型 |
| 同步与混音 | 所选框架组织音轨和锚点；重点动作、音效与配音的到达关系由导演决定 |

先根据听感决定是否需要 BGM 或音效。纸张移动、数据刷新、物件落定可有材质相关的声音，也可留白。不要为了“有声音设计”给每个元素加 whoosh；静音同样可以形成注意力变化。

测量响度、峰值和动态后按目标与素材处理；不只用峰值或 RMS 宣称混音合格，不套固定万能数值。实际播放检查配音是否被遮盖、音效是否造成额外紧张、段落转折是否有声音层次。播放状态、帧数推进和音轨存在只证明技术运行，不能证明已听到或已评价听感。

无法听取声音时，保留原口播与独立音效轨，把新增声音标为提案；需要比较时导出同一画面的纯口播和音效版本。锚点、增益、来源和处理应可追溯；不要因此强制每个项目制作两个版本。用未损失的源音轨与导出音轨核对延迟和截断，避免重复转码产生的位移；对齐检查仍不代替听感审阅。
